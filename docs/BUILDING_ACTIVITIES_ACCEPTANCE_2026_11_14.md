# 建筑活动、日历地点匹配和抽屉验收｜2026-11-14

## 原因与回归

负责人列出的 `大学城校区E203`、`南校区D512课室`、`大学城校区G座教学楼207`、`大学城校区院系楼401会议室` 原先全部返回null。`articleMapPlace` 仅将字符串与现有地点全名/长别名做包含匹配，缺少教室编号、字母楼栋表达与“院系楼”简称。日历API是在读取时计算mapPlace，并非按钮缓存或需要重新采集文章。新增4项最小回归在修复前全部失败，修复后通过。

建筑详情原先只配置向下滑动关闭，没有snapPoints，手机框架固定最大57dvh。线上585×871视口实测向上拖220px，高度始终399px，不能拉伸。现在复用既有Base UI Drawer与助理相同的0.62/1两档停靠，提供拖动、展开/收起按钮及键盘上/下/Home/End；桌面原侧边卡片保留。内部内容独立滚动，原关闭、导航、焦点恢复与减少动态设置保留。

Base UI注册的位移CSS变量不继承到子节点，直接在frame中引用会造成内容框比可见区高。已在Popup处转为本模块可继承偏移，让frame高度跟随拖动与停靠变化，底端保持贴合可用区域，解决半展开时底部内容无法滚动到的问题。未添加第二套手势库或改地图渲染。

## 功能

- 地点规范化支持全/半角、空白、教室编号与字母教学楼表达。E203、D512、G座教学楼207分别落到已有教学E/D/G栋；院系楼401落到已有院系办公楼。室号只用于确定建筑，不生成教室、楼层或入口坐标。
- 可使用日历已提取的明确university_town校区上下文；白云/北校区、线上、未知校区且无明确校区证据或多个建筑的地点继续不映射。主办方不是场地依据，例如“图书馆”主办的E203讲座定位教学E栋。
- 建筑详情按 **简介 → 图片 → 活动** 排列，最多5条，余下进入“更多活动”二级页；返回恢复概要，原“更多图片”可继续使用。活动点击打开原有站内文章阅读框，保留来源与原文入口；标题使用原文章标题。
- 复用 `/api/public/activities?placeId=<已有ID>&limit=5`，从同一D1日历索引动态查询，不生成新的活动副本。保留原来源公开视图、版本/内容哈希、正文使用范围、取消/延期及隐私门禁，查询无写入、无模型调用。
- 按服务端北京时间，包含结束日期在今天及以后的活动；有明确结束时刻但今天已结束的场次仍按负责人“今天以及以后”要求列出。跨日持续活动保留，过去日期排除，不限定当前周或未来30天。按发生日/时刻排序，游标绑定建筑与当天日期；超过5条时二级页读取后续批次。教学E/F/G组楼可汇总已有子楼栋，单独E栋仅显示E栋的活动。
- 原日历日期查询与游标格式兼容；既有历史活动保留，修复后的地图入口也适用于历史日期。未重新抓取、重做OCR、重分类或修改原活动索引。
