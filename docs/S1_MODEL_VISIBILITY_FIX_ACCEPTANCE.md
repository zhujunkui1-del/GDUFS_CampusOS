# 地图模型完整显示与宿舍2.5D统一（2026-11-02）

负责人指出四项实际问题：3D中的其他楼体仍是白模、只有靠近才显示立面、平移后已显示的模型退回白模、南苑7栋2.5D明暗与其他宿舍不同。本轮在本机`http://127.0.0.1:3026/map`修复并复验，覆盖初次集成报告的距离/数量降级策略。

## 原因与行为变更

旧策略在zoom≥18才自动加载细节，桌面最多4个、手机最多2个，再按中心距离和面数/调用预算回退为2.5D或二维。平移结束重新排名，非活动模型只留6个。因此资产本身虽完整且逐栋选中可显示，普通整片浏览却不能稳定保留立面。南7另外走MapLibre原生挤出，其余宿舍走Three材质/灯光，造成两套明暗。

3D现在按模式加载全部已完成模型并保留到地图卸载，不依赖选中、中心、距离或缩放阈值，不因平移释放、重取或切回体块。只有真实文件失败才降级，切换模式仍可重试。2D/2.5D/3D按钮及模式切换不重新聚焦、地图范围、地点/导航规则保持。

模型按128米空间格、等效材质及顶点格式合批；Three视锥负责剔除屏幕外绘制。平移只更新地图投影，不重建几何/批次。取消以缺失立面满足固定数量/旧建议预算的做法；GPU量按实际视野变化，保留静止无额外动画循环及卸载释放。

南7的2.5D采用既有宿舍模型包中的轻量资产，与另12栋共用同一渲染器、材质、环境光和方向光。21米、原外环与院落不变；共享体块就绪后隐藏原生层，原生挤出参数仍保留为模型层失败回退。原80384字节V2 3D及SHA不变，3D仍用原文件和灯光，去掉原16.7级显示限制。
