# 统一文章内容分析契约（M1）

一个入口接收标题、原阅读HTML/正文、正文状态、来源与原文URL、发布时间及现有类型；`articleText`产生带稳定偏移的文本投影，原HTML不改、不执行脚本、不下载图片。

主栏目为radar/knowledge/unknown；业务分类继续复用既有七类/六类。同一文章保持唯一ID及主栏目，混合用途只记录辅助用途/证据，不复制文章。未可靠识别时两类业务字段均为null，不默认campus_notice。栏目与short/long/mixed/unknown时效类型分开，原发布/手动下架/门禁不由分类器修改。

专题标签复用document_tags和TopicTagsSchema；原6个值原样保留，扩展为明确列举的校园招聘、毕业生、就业服务、就业协议、奖助、选课、图书、科研、办事等词条。数据库原本允许1–40字符且最多12个标签，扩展允许值不需要重写旧行；旧6值为恒等映射，无任意字符串入口。

报名要求继续使用required/not_required/unknown；只有明确报名证据才有“报”标记，截止与否不改变该标记。日期精度沿用date/exact_time/unknown，另以resolution区分day/minute/second，防止补零秒被当作原文秒级精度。所有点保存raw、Asia/Shanghai、证据偏移和推断依据；没有时刻不生成23:59，没有可靠年份不填年份。

分析结果是与当前内容修订/哈希绑定的派生数据，后续持久化须避免改栏目触发撤回批准、公众号同步分类参与旧哈希造成覆盖。管理员修正优先。未知内容仍保留原文章和可公开元数据，通过明确的待分类投影兼容现有自动发布，不能为了数量均衡强制归类。

classifierVersion与输入语义哈希用于增量处理，重复输入不重复分析/写入；公共页面读取已保存结果，不现场运行模型。规则置信度为high/medium/low，不是校准概率。可选模型只对未决情况、在现有明确授权范围内使用，本次首先实现规则与证据校验，默认模型调用0。
