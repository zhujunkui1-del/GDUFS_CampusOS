## 2. 工具复用边界与稳定性

上轮初稿对所有只读工具复用过宽，现收紧为显式`reuseResultMs`策略：

| 工具                              | 策略                                                         |
| --------------------------------- | ------------------------------------------------------------ |
| search_places / get_place_details | 同一Run、同一固定数据快照，最多5秒，成功且已验证结果可复用   |
| find_nearby_places                | 不缓存；每次重新检查中心及定位授权/期限                      |
| plan_route                        | 不缓存；每次实际计算并校验会话、路线期限/版本                |
| control_map                       | 不缓存；每次验证地点/路线/模式，动作包仍需单次领取与执行回执 |
| 其他/写入/本人查询                | 默认不复用；写入或非公开Skill不能启用该公共快照策略          |

缓存只在`AgentOrchestrator.run`局部存活，不跨请求/用户/Worker。键包含可信主体、身份/角色、权限、校区、Skill版本、名称及规范化参数；权限在每次调用和复用前重新检查，模型调用ID仅用于协议重复/冲突检测。过期重算；不能安全重放的相同调用ID被拒绝。不存在写入缓存或用调用ID代替所有权。

确定性回归先见红：相同参数换ID执行2次；修复后执行1次。另测跨Run/主体不复用、权限变化拒绝、5秒过期执行、非批准查询仍执行2次，原12工具/6轮/Token预算保持。计数改善不能直接当作真实模型延迟改善。

保留最多一次必要工具纠正、6上游请求、4096输出Token、90秒运行/15秒上游超时。失败不输出未核实地图成功，绝不无限重试或自动切换供应商。

用户选地点、修改起终点、手动规划/定位/缩放/旋转/拖图会更新交互版本；迟到AI动作拒绝执行。内部镜头拟合不被误判为用户手势。原中止请求、所有者取消台账和pending/claimed撤销保持。

生产构建、OpenNext、Wrangler本地预览与preview环境dry-run通过；最终打包12572.96KiB，gzip2165.40KiB。dry-run没有创建资源或部署。当前[Cloudflare官方限制](https://developers.cloudflare.com/workers/platform/limits/)为Free CPU10ms、128MB、每请求50个子请求，Worker未压缩64MiB；大小检查不能证明CPU/启动时间或运行兼容。等待网络不计CPU；现有15秒地图回执轮询遇慢客户端可能超过Free子请求预算，需真实预览计数/故障测试，必要时再做最小优化或经批准选择套餐。本轮没有宣称Free套餐已可稳定上线。
