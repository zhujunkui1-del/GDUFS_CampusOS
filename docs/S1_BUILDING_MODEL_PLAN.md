# 广外建筑自主 2.5D / 3D 建模评估

2026-10-13。负责人要求：先解决满屏地图与极限缩放边界，再考虑自主建模。**当前只作资料与方案评估，未生成或集成建筑模型。**

## 可复用的基础

已有 OSM 建筑平面轮廓、稳定来源ID和 WGS84 坐标，可将经过核验的轮廓用于独立建筑层。对应高德的 GCJ-02 转换继续使用官方服务。体育场地与游泳池作为地理平面保留，不统一挤压成建筑。

负责人新提供的 XML 与 GeoPackage 同源，不能充当两份独立高度证据；目前没有校方批准的立面、楼层尺寸或模型资产。参考鸟瞰图不是测量模型，也不能用于推算未经证实的建筑高度。

## 推荐分两步

1. **自有 2.5D 建筑层**：逐栋审查足迹、名称、楼层/高度来源；有真实高度才挤出，无高度的保持平面轮廓。按缩放控制细节，选中高亮与原地点ID一致。来源记录与可导航入口继续分离。
2. **重点建筑 3D**：先选图书馆、体育馆等少量地标；取得可使用的照片、平面尺寸与楼层资料后建模。每栋独立加载，设不同细节等级、移动设备预算和2D回退。模型不遮挡入口、路线与地图标签。

沿用 MapAdapter 与既有地图引擎；是否使用官方自有模型层或 Three.js 自定义层，需先做一个有真实资料的地标性能验证，再确定依赖。暂不替换核心引擎，不批量猜测建筑高度、不复制高德楼块模型。

## 需要的资料

- 校方/负责人核验的建筑清单、轮廓调整、真实高度或楼层与层高。
- 自有拍摄或可公开使用的照片、立面/平面资料，以及权利与更新时间。
- 每个模型的允许精度、来源版本与审核人；需要真实手机测试设备。

## 后续验收

真实位置/朝向/比例、与底图坐标一致；不同缩放和设备的加载预算、内存和帧率实测；路线/入口无遮挡；缺资料建筑保持真实缺项；模型与素材许可台账完整。预算目标与性能结果须分别记录，不能以渲染截图推断性能合格。
