## 数据与权限

- `site_visit_settings`：单行起点。
- `site_visit_days`：日期主键、当日PV、截至该日累计。按SQL服务器北京时间收件日期归档；累计读取最后一行，近30天索引范围读取，补零只发生在已开始统计的日期。
- `site_visit_batches`：匿名随机批次ID、1–20浏览数、收件时间。INSERT OR IGNORE + 同事务触发器防重。重复重试在48小时回执保留期内不增加统计；过期记录随机触发有界64行清理。没有IP、账号、设备指纹、Cookie和页面URL列。
- 访问写入保留同源、256字节Schema、现有边缘限流。边缘限流沿用其他公开接口的IP键，不向D1新增IP记录。计数不依赖Agent模型密钥。
- `external_source_session_state` 只保存来源、状态、检测时间。Cookie/LocalStorage继续只在本机专用Edge profile，后台与D1不接收这些凭据。

管理端 `/api/admin/v2/traffic` 沿用Console认证；`source-session`的GET/POST还要求admin角色，写入沿用Origin/CSRF。状态包括已登录、需重新登录、需安全验证、未知及不可连接。离线与检测超时不会伪装成已退出。

状态/登录控制复用0050的短期D1任务和现有出站执行器，独立`session_control` Schema。公开Agent搜索输入仍不允许登录控制。机器回调继续使用现有服务密钥；短期二维码只在管理员本人响应和约31秒临时任务结果中，响应no-store，随后删除。状态快照没有二维码。

`重新登录`在会话有效时保留现有登录；需要登录时刷新来源登录页面，只截取真实可见二维码，管理员用手机扫码确认。请求登录后最多4分钟仅本机轮询；云端仅报告状态变化，后台仅在二维码等待期间每5秒读快照。二维码显示有效期为应用保守上限3分钟，源站提前失效仍需重新获取。安全验证由小红书要求，在来源电脑专用Edge中本人完成，无验证码破解。
