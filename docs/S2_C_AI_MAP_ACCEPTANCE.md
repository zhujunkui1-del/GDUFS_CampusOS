## 2. 对话与地图执行链

```text
原全局面板 → POST /api/agent/chat → 可信会话/额度 → 原 ModelRouter
  → 原 AgentOrchestrator → 原 Tool Executor → 五项真实地图 Skill
  → 严格卡片/动作包 → 前端领取、复验 → 原地图控制器执行
  → 浏览器回执 → DeepSeek 最终文字流 → D1 有界历史
```

- 工具规划阶段不展示模型叙述；供应商 `reasoning_content` 丢弃。最终回复使用真实上游流，非逐字播放静态答案。缺起点的问句先完整校验再显示，禁止复述旧路线或虚报距离。
- 地点、路线、地图动作均有 Zod Schema。服务器验证真实 ID、所有权、版本、有效期；前端再次验证几何/距离/边界与 MapAction，无法传入 JS 或地图内部对象。
- `FOCUS_PLACE`、`SHOW_PLACE_DETAILS`、`SHOW_ROUTE`、`CLEAR_ROUTE`、`SET_VIEW_MODE` 接到原 Provider。服务端路线经受控适配载入原路线缓存，再调用原渲染器，没有重建地图。
- 保留 600ms 可打断、由快到慢的镜头与原安全可见区域；地点点击原规则不变。手机执行地图动作自动收起 AI，失败重新展开；对话保留，进入专注导航沿用原精简 UI。
- 等待实际镜头完成、3D 资源 ready 后才回执。3D 失败回退不会被声称切换成功。动作被用户后续选点/模式操作打断时，不继续执行旧批次。
- 工具失败立即结束；具体查找和已知起终点路线要求真实工具。若模型跳过必要工具，本轮最多纠正一次，计入同一请求/Token 预算；仍跳过则拒绝文本，无未经确认的替代操作。
- 停止请求同时中止 fetch、撤销待执行动作并调用服务端取消；已执行的合法操作不作隐式回滚。断线不自动重放动作或自动重试付费请求。
- 桌面右侧面板、手机原底部抽屉；正常字号状态、地点/路线卡片，无新增一级 AI 页面、内部推理或解释性小字。卡片可再次聚焦/显示路线、进入原步行导航。

## 3. 共享会话、路线与一致性

### 3.1 D1 主体与持久状态

选择现有 D1，未增加 KV/DO。会话、配额、动作与公共建筑路线需要读到当前主库状态；DAO 每个关键操作使用 `withSession("first-primary")`。配额在单个 SQL INSERT 的 BEFORE trigger 内一起预留；多语句清理/取消使用事务 batch。设计依据：[D1 Database API](https://developers.cloudflare.com/d1/worker-api/d1-database/)。本地双 isolate 检查不等于云端多地域验证。

- 游客 HttpOnly `campusos_assistant` 随机 Cookie，只存 SHA256；SameSite=Strict、HTTPS 下 Secure、Path=/api。
- 登录主体只来自服务端 `login_sessions` 哈希匹配、未过期/未撤销且 active 的 users。客户端 userId/role 不建立身份；登录/撤销切换隔离主体，原游客会话不自动归并。
- 同源限制、严格请求 Schema、96KiB/5s 接收上限。仅本地预览同协议同端口的 localhost/127.0.0.1 别名等价，其他 Origin 拒绝。
- 会话/历史/动作/路线均绑定 owner；未知或他人对象统一拒绝。动作包 5 分钟、单次原子领取，重复领取拒绝；失败/取消撤销 pending/claimed，客户端有请求代次和交互版本防迟到动作。

### 3.2 路线恢复与定位隐私

建筑到建筑路线的完整真实快照保存在 D1；新的 Worker/运行时可按同一主体读取。路线统一 10 分钟，绑定固定地图/路网版本；过期或版本变化要求重新规划，不用历史几何伪装有效路线。

设备起点路线的 D1 `payload_json` 为 NULL，只保留 owner、ID、版本和过期元数据；精确几何封装为 HMAC-SHA256 完整性保护的短期票据，仅当前页面内存持有，通过 POST 发送，不放 URL/localStorage。票据有主体、有效期和服务端版本检查。运行时切换可凭合法页面票据恢复；刷新后不恢复精确定位路线，应重新定位。这是明确的隐私选择，非全量持久 GPS 轨迹。

仅用户明确询问“我的位置”等时调用一次浏览器 geolocation。30 秒主体绑定一次性 challenge、坐标范围/精度/时间校验；Tool 参数无任意坐标或 consent 布尔值。拒绝或失败时以空地图工具集让真实模型询问手动起点，不能改用历史地点冒充当前位置。定位数据不进入模型提示、会话卡片/历史或日志。普通 Web 服务器无法证明客户端坐标确来自硬件或权限弹窗；nonce 是重放和工作流约束，不是设备定位认证，坐标不承担身份/权限证明。

### 3.3 容量、额度与清理

| 项目                  | 当前限制                                                                     |
| --------------------- | ---------------------------------------------------------------------------- |
| 主体有效期/对话有效期 | 48 小时；对话有新消息时续期                                                  |
| 历史                  | 最多20条；入模型最近10条、JSON≤16000字符；单条保存≤4000字符                  |
| 存储容量              | 会话10000；对话每主体5/全站5000；路线每主体100/全站10000                     |
| 共享并发              | 每主体1、全站4；运行租约120秒                                                |
| 请求额度              | 游客20/小时、30/天；登录60/小时、120/天；全站200/天；哈希IP120/小时          |
| Token 预留            | 每运行250000；游客600000/天、登录2000000/天、全站5000000/天                  |
| 模型运行              | 总90秒、上游单次15秒；最多6上游请求/6轮/12工具；总输出≤4096、单次≤1024 Token |
| 清理                  | 新建主体/每次聊天按需清过期项，运行台账保留48小时并回收超时租约；无无界历史  |

完成且 usage 完整时按真实报告释放多余预留；取消/断线 usage 不完整保守保留预留额。这是额度记账，不是供应商实际收费。删除 Cookie 会形成新游客，但站点/IP/Token 上限仍约束平台支出。未增加定时清理部署，空闲站点的过期行在下次请求清理且不会无限增长。

| ------------------------------------------ | ----------------------------------------------- |
| GET /api/agent/session                     | 可信主体、最近有界历史、模型就绪状态            |

本机已应用 `0004_assistant_shared_state.sql`。Next dev 使用 OpenNext 官方开发绑定代理访问同一本地 D1；不要同时启动两个独立本地 D1 模拟器写同一个持久目录。

服务端凭据：既有 `DEEPSEEK_API_KEY`/默认模型能力验证变量，加新 `AGENT_SIGNING_SECRET`（至少32字符，推荐32随机字节）。真实值仅 `.env.local`/`.dev.vars` 或 Cloudflare Secret。所有公开接口不返回凭据；不配置模型/数据库时公开地图照常独立工作。

能力记录24小时失效，供应商/模型/Key/策略变化重跑 `npm run model:verify`，状态接口不自动消耗模型额度。正式部署前各环境独立配置 Secret、D1 真实 ID、迁移与 HTTPS；当前没有云端部署。

## 7. 剩余边界与 S2-D

本轮只开放公共地图 Skills。真实登录/SMS/学校授权、个人数据访问、RAG、活动与完整 BYOK 未实现，账号隔离验证使用隔离数据库的有效服务端会话，不宣称已经有用户登录流程。

真实手机硬件GPS、触控/键盘/弱网/热机性能，以及云端HTTPS、多地域D1/限流/中断和正式成本阈值仍需 S2-D。新签名密钥轮换会使旧设备路线票据失效，应重新规划。精确定位路线刷新不恢复符合当前设计。

可进入 S2-D 进行云端与真实设备验收；本地功能通过不表示已经正式开放公网。建筑批量建模继续暂停，南苑7栋保持已验收视觉。
