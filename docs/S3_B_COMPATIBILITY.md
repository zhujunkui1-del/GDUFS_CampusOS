## 2. 兼容与安全不变量

- 既有DAO、管理员身份、CSRF、每次权限检查、命令指纹/CAS、事务审计、版本恢复和失效outbox复用。
- 业务version变化不必改变content_revision；标题/正文/原发布日期/来源等输入变化才改变input_hash。审批绑定修订，发布后不自我失效。
- 旧快照不改写，不生成伪SHA。旧记录默认修订0/hash NULL/权利unknown，在重新保存和审核前不可公开；原审核状态/内容保留。
- 不改变学生地图、Agent、会话、路由算法、南苑7栋或220条来源人工状态。
- 所有新数据先待审，抓取/解析/审核/发布分别计数。未知许可不全文镜像，人工提供链接可独立使用。
- 未批准模型新预算，使用可验证确定性提取；Dify未接，不探测内网。
