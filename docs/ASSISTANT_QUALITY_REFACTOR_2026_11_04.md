## 真实调用链及根因

```mermaid

 A[输入及发送时搜索快照] --> B[输入闸门与对话行为]
```

1. **日常聊天在模型之前被拒绝。** Preview 基线中“你好，你是一只大肥鱼吗？”和“今天好累，陪我聊聊天”均返回校外拒答，模型请求为 0。闸门先于已存在的会话行为识别与 Persona。
2. **标题约束失效。** 指定标题不存在时仍放行其他 FTS 命中；标题补查又无条件执行短前缀。“党的二十届五中全会公报一图速览”真实基线引用了目标文章、党建征集、挑战杯。
3. **正文权限与文档存在被混为一谈。** 三个公开样本保留 source.manual_rights_scope=metadata_only，而文档与索引为全文。旧检索直接丢弃整篇；现在在不提升权限的前提下返回真实元数据，禁止传入正文/活动分析。详见 public-index-audit.json、public-policy-audit.json。此限制仍存在，未擅自修改来源许可。
4. **口语标题被普通主题召回稀释。** “资讯 _ 校园卡补办”等完整标题仍夹带通用信息化指南；现以安全规范化标题候选优先，并在命中完整标题时限制该阅读范围。
5. **未知主题限定被丢弃。** 旧查询表示在主题字典没有条目时丢弃 modifiers，导致三下乡、全运会被申请或学生获奖等宽词取代。现在保留原始限定；明确冲突年份排除，缺年份与年份冲突分开；必要的语义提取只接受来自原句的文字片段。
6. **新人物被当成旧主题翻页。** “还有王春业老师的介绍吗？”继承竞赛。现只将完整的结果反馈作为翻页，显式人物优先；翻页游标来自实际来源时间戳+ID，不再从回答猜日期或固定写2026。
7. **活动证据错误复验。** 日历的 activity_projection/excerpt 被拿来与 FTS full_text 比较，真实“今天有哪些活动”返回 CONFLICT。现由同一 readCalendar 服务按事件 ID、当前公开状态、文档版本及哈希复验。
8. **已知字段再次被模型改写。** 法学院比赛基线已有截止时间，生成却称未注明，校验修正耗时至90秒超时。列表型请求现在直接格式化已核验条目、日期、地点与报名状态；复杂说明继续生成及证据校验，未增加重试次数。
9. **渲染层删除加粗且没有 Markdown。** 已替换为 react-markdown+remark-gfm；引用在文本 AST 节点中转换，代码块、链接不会被当作引用处理。
10. **真实 Preview PATCH 没有转发。** 新会话设置 API 在 Next 路由可用，但轻量 Preview dispatcher 漏了 PATCH，实际返回405；已补正式转发与回归。设置同时增加版本号以避免旧历史响应覆盖刚确认的切换。
11. **D1 表达式深度问题。** 标题规范化直接嵌入复杂公开视图曾导致公共搜索500，已以真实 D1 重现；现先匹配标题候选 ID，再执行既有公开查询。public-search-live-d1.json覆盖无栏目、雷达及知识+来源筛选。

## 最终实现

- 文章身份、分类与公开门禁继续使用原有文档/视图；标题规范化工具同时用于公开查询与检索。标题召回只扫描元数据，至多16个文档候选，每文档至多6个片段，再进行当前公开资格复核，不扫描完整HTML或在页面重建索引。
- 保留原 FTS、多路候选、Vectorize 补充及结构化活动查询。此次维护脚本的100题对照只测词法路径；没有把未实测的向量改善计入指标。
- 模型看到的 hits、knowledge、activities 都限制为准入证据；最终只保存实际引用的来源并重排编号。仅标题可确认文章存在，署名/转载说明不能当作正文总结。
- 大肥鱼人格沿用 campus-dafeiyu-v1 契约和已保存的 MIT 许可。日常对话实际进入生成，专业场景不强制固定“本鱼”开场；保留退出、恢复、简洁偏好与严肃收敛。原上游仓库本次读取返回404，没有宣称重新取得仓库全文。
- search_external_campus_info 保留为普通网页补充；注册层不再执行 searchXiaohongshu，不再走专用 Cookie、浏览器会话或 native relay。服务及凭据未删除；普通搜索发现的小红书公开网页仍按普通来源处理。
- **智能搜索默认关闭**。请求必须携带 smartSearch；关闭时 registry 不暴露外部工具，执行层仍验证策略；明确上网但关闭时提示开启。开启时内部优先，显式联网或证据缺口可调用一次普通网页补查，官网问题限制官方网页。模型切换不改变权限快照。
- 设置按经过所有权检查的会话 system 元数据保存，不进入模型历史或用户消息；递增版本阻止旧响应覆盖。协议3提供偏好和版本，旧协议保持兼容。无需新增迁移；账户历史与游客范围沿用原规则。
- Markdown 支持段落、标题、列表、加粗、引用、表格、代码块和安全链接；不启用原始HTML，不加载模型生成的远程图片。正文为可点击[n]，完整来源留在折叠组件，移动窄屏表格独立滚动。沿用 HarmonyOS Sans 与现有蓝白面板。
- StepFun优先、明确额度耗尽才使用DeepSeek、个人API选择和既有预算均保留。

## 评测口径与结果

冻结公开语料33篇，按实际分类分层抽样；100题为完整标题、缩写、口语标题和请求包装。expectedId 来自真实公开数据库，不是生成的回答。基线使用 ff5340f 隔离只读代码与同一冻结语料；结果可用 evaluate-assistant-quality.mjs 重放。

最终数值见 `summary.json`，保留以下重要区分：

| 指标 | 旧版 | 修复版 |
|---|---:|---:|
| 目标文档 ID Recall@5 | 91% | 100% |
| 等价标题 Recall@5（同文其他来源也算） | 97% | 100% |
| 有资料却未召回等价标题 | 3% | 0% |
| 返回Top3字面标题相关比例 | 80.41% | 100% |
| 返回Top5字面标题相关比例 | 77.41% | 100% |
| 检索写入 | 0 | 0 |

Top3/Top5 为“返回标题是否匹配所请求的字面标题/缩写”的相关比例，**不是全部校园语义问答准确率**。维护延迟包含 Cloudflare API 往返，不等于 Worker 延迟；本次均值1973ms→1672ms。D1 平均读取在限定标题候选后从约22,377降至约2,102行。正文覆盖率95.41%→86.24%，原因包括以前被丢弃的受限来源现在作为元数据返回；未把它们标成已取得全文。

另保存8条前后实际模型回放与20条核心场景：人物、秋之声、竞赛/讲座发布时间、法学院比赛、研究生奖学金公示、文章标题、多轮、新主题、日历、报名、联网开关、普通网页搜索、Persona退出/恢复及正式语气。初轮失败和修复回执均保留，不以HTTP200代替判断。已取得的20题回放外部关闭调用0、普通网页补查2次、native小红书供应商0；实际引用与来源可从每条 cards 和正文编号核对。

DeepSeek 对5题相同来源卡片做开/关Persona表达对照，共10次真实请求；与平台Step实际回答并列保存于 persona-model-comparison.json。两侧不是完全相同的完整Prompt/历史，不声称这是严格的全量跨模型消融实验。个人模型使用同一权限/表达链，但没有借负责人私人配置做本轮真实供应商调用。

## 真实限制

1. 100题是检索对照，不是100题完整模型生成的前后基线；独立的语义相关性、事实支持率和Persona自然度不能用这个命中率代替。模型grounding verdict是机器判断，未伪装成独立人工评分。
2. 当前无法合法读取正文的来源仅返回元数据；未抓到的海报、附件内容不补造。三下乡/2025全运会等题必须以实际准入证据决定是否能够回答，未命中不宣称学校没有相应资料。
3. 普通网页搜索可用性以每次供应商回执为准；失败会保留站内证据，不保证取得每个网页的正文。
4. 本地文件中的Step凭据在隔离诊断返回401；没有更换云端平台密钥，云端Step实际对话另有成功回执。未完成30题完全相同Prompt/证据的Step/DeepSeek/个人供应商完整对照。
5. 未采集Worker CPU账单样本，未做500人负载测试；手机测试为浏览器视口，没有声称实体手机验收。
6. 运行中出现一次客户端Socket中断，保留日志；评测只补跑未完成题，没有将未收到终态视为成功。

补充负向验收发现并修复：明确找文章时，标题中的人格词不能绕过检索；“官网最新资料”中的来源/时新性不能成为硬正文关键词。search-state-live.json 对不存在标题要求实际调用站内检索且不假称搜遍全网，对官网最新资料要求返回发布时间列表并真实调用普通网页补查；连续3次PATCH要求服务端读回相同开关及递增版本。较早的宽泛问题失败回执保留，不能仅凭其终态completed声称业务通过。

因此，本报告交付已实现及实际验证的核心改造，不宣称所有自然语言问法均零错误，也不把上述未覆盖指标标成通过。
