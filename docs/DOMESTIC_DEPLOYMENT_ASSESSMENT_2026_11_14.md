# 国内部署评估（2026-11-14，暂缓）

负责人确认目前 `gdufs.zhiyuapp.site` 国内访问较稳定，本方案仅留档；本轮不部署阿里云、不调整 DNS、数据库或网站架构。恢复实施以负责人后续指令为准（D-165）。

## 只读核实结果

阿里云广州轻量服务器 Ubuntu 24.04、2 核 CPU、2 GiB 内存、40 GiB 系统盘、200 Mbps 峰值带宽。控制台查看时 CPU 2.17%、内存 0.42 GiB、磁盘 2.84 GiB；这些是单次快照，不是应用运行压测。未登录 SSH、修改服务器或申请新资源。

线上 `campusos-preview` D1 的 Wrangler 只读元数据：537 MB、104 张表，运行区域 APAC；近24小时132,237次读查询、33,088次写查询、286,715,199行读取、96,145行写入。包含采集等后台任务，不能换算成用户访问量或峰值并发。

本地当前构建：`.open-next/assets` 43.99 MiB，服务端构建目录39.62 MiB。`public` 33.16 MiB，其中地图目录12.14 MiB、模型目录6.57 MiB、字体12.51 MiB；子目录包含辅助/历史文件且已计入总量，不重复相加。地图选定底图约2.45 MiB，活动清单为82个GLB。以上是本地磁盘体量，不是线上Worker完整包、首次页面下载量或运行内存。

## 可行性与路线

现有机器适合先验证 Nginx + Node.js 主站 + 小型数据库，AI继续调用外部模型接口、构建在本地或CI完成。磁盘充足；2 GiB内存下不宜把浏览器采集、独立向量推理等服务一并集中部署。未取得应用峰值内存、HTTP并发峰值、月流量套餐或广州到上游的实测，不能承诺容量和延迟。

| 路线                                                 | 收益                                           | 需解决的问题                                                                                                    |
| ---------------------------------------------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 国内入口和本地静态资源，动态HTML/API回现有Cloudflare | 地图、建筑、字体、JS从国内提供；保留D1单一权威 | 动态页面、账号、检索仍依赖广州到Cloudflare链路                                                                  |
| 完整迁移主站/API、数据库和调度到国内                 | 核心动态服务减少跨境依赖                       | D1适配与全文检索/触发器/事务验证；Workers AI、Vectorize、服务绑定、定时任务、搜索容器/浏览器/存储逐项替换或桥接 |
| 后续用OSS＋中国内地CDN分发静态资源                   | 降低单机带宽压力，改善分发                     | 备案通过后的域名接入、缓存及费用配置；当前尚未购买/实施                                                         |

完整迁移技术上可行，但复制代码后直接 `npm start` 不足以复刻现有Cloudflare绑定。迁移账号和历史数据需保留必要签名/加密密钥；数据库维持单一权威写入，采集调度避免重复执行。改用服务器数据库将涉及现有D1架构基线，实施前另作明确决定。

## 技术依据

- [Next.js自建部署](https://nextjs.org/docs/app/guides/self-hosting)：支持Node部署和流式响应；反向代理需保证流式输出。
- [D1导入导出](https://developers.cloudflare.com/d1/best-practices/import-export-data/)：可导出数据；本项目全文索引和触发器仍需实际恢复验证。
- [阿里云轻量服务器使用须知](https://help.aliyun.com/zh/simple-application-server/product-overview/usage-notes)：适合低负载、突发应用；200 Mbps为峰值上限，不是保障带宽。
- [CDN域名接入](https://help.aliyun.com/zh/cdn/add-a-domain-name)：中国内地/全球加速需要域名完成备案。
