## 定位与步行流程

- 用户点击定位才请求浏览器设备位置，按WGS84处理，显示位置/精度圈；区分权限、不可用、超时、非安全上下文、校外、精度不足。校外位置不会被夹到校园冒充定位。
- 起终点输入必须选中真实地点建议，也可点选道路或地点标签，可交换、重算、重置。未匹配文字不会使用旧地点规划。
- 同区调用真实高德Walking，检查端点、有效路径/距离/时间及校园范围，只绘制道路路径。建筑中心不是入口，结果明确为附近道路。
- 规划后进入2D；点击开始步行导航才开启设备位置追踪，可靠位置投影到实际路径，更新剩余距离与当前步骤。偏离、低精度或30秒无新定位不推演移动；不自动重算、扣用新额度。
- 关闭/结束、离开地图页、转入后台或卸载均停止追踪。定位拒绝保留路线和步骤。位置仅在页面内存，不写存储/数据库/日志；确认规划的起终点按UI告知发送至高德，导航过程中位置不会自动上传。
- 本地隧道候选网络取7条明确foot=yes/designated的源way，10节点/10边，使用真实共享节点，不凭坐标邻近造连接。`walkway-review.json`当前approved=false。开通后仅覆盖隧道及两端步道，不能声称任意宿舍到教学楼均已连通。
