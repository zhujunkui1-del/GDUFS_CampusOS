## 交互

1. 图层开关只隐藏对应标签，体育场地/建筑地物保持显示。
2. 定位通知可关闭并约6秒自动消失；详细错误留在导航状态中，不编造定位成功。
3. 地图点选起终点保持当前视角；文字选择建筑后平滑聚焦。聚焦与整条路线拟合依据搜索、步行面板、详情和AI的真实占位，把地点/线路放到无遮挡区域。
4. 镜头采用已有ease-out曲线和约220ms过渡；在独立投影副本计算目标，修正过程不产生可见跳帧。用户手势/新操作能打断，减少动态效果时即时切换。倾斜前先满足数据覆盖缩放条件，平面导航可缩小到完整长路线，地面视口仍被约束在本地覆盖内。
5. 开始导航进入专注界面，隐藏搜索、普通导航、图层、详情和AI；上方显示方向/当前段距离，下方显示总路程/剩余距离、预计时间与到达时间，侧边定位、退出、朝北/路线朝上、2D/2.5D控件。退出保留路线/起终点；AI会话不因隐藏窗口清除。
6. 3D建筑尚未建模，3D入口禁用并说明状态，不能将倾斜平面冒充完整3D。GPS失败仍保留导航界面和真实路径，不模拟行走；定位仅在当前页面内存，退出/后台/离页停止追踪。
