# 南苑7栋模型证据

2026-10-14，Workers本地生产预览3000。来源为固定本地OSM、负责人7层/约21米及自有程序化模型。外观/中庭近似，无照片纹理和个人GPS。

- `edge-display`：当前Edge用户配置的实际显示JPEG，2.5D/3D；未经像素编辑。
- `chrome-production-final` / `edge-production-final`：桌面1440×900/DPR1、手机视口390×844/DPR3的2D/2.5D/3D/旋转截图及模型字节、绘制/三角形、视口边界、600ms镜头证据JSON。浏览器手机视口不等于真实手机。
- `chrome-native-window` / `edge-native-window`：两款真实浏览器原生窗口/页面缩放快速检查，150%、450px高窗口和650px+150%等配置及measurements.json。本轮没有重跑所有110%—300%条件。

最终完整回归两款浏览器各53通过/5跳过，原生窗口分别另行1通过；45单元、类型/Lint与生产构建通过。早期调试及重复其他模块截图因自动安全策略拒绝批量删除而保留本机，已用定向Git忽略规则隔离；既有S1里程碑证据未改动。[详细验收](../../../S1_NANYUAN7_MODEL_ACCEPTANCE.md)记录命令、近似项及依赖。
