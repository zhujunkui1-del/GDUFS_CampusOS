## 资源与渲染

`scripts/publish-campus-building-models.mjs`验证原稿版本/源轮廓、SHA和字节，将54份建筑GLB原样复制至public；另外按教学V2 design参数生成两份不可拾取的连接段GLB。56份共5,156,888字节，全部零images、零textures、零外部buffer；30个院落仅作底色。来源、批准、ID、WGS84原点、包络及两模式资产记录在`src/features/campus-map/data/building-model-catalog.json`，public附SOURCE.md。参考照片未发布。

新增模型共享MapLibre GL上下文，静态面按材质合批、重复构件实例化，保存每段面/实例的建筑归属用于拾取。按视野加载、最多3个并发文件，有限保留6个非活动对象，离开地图释放资源。默认2D不加载本批几何；南7原有预热保持。新增模型没有常驻动画循环和逐帧React更新。

3D远景使用低细节，近景预算最多桌面4个/手机视口2个高细节，选中对象优先。手机出现高细节时累计模型成本，并为可见南7预留4800面/8调用；超过30k面/20次调用时降低细节或让远处建筑沿用原二维底图。标签开关只切标签；模式切换不重新聚焦；导航时模型透明度为0.42，关闭导航恢复原材质。单个高细节文件失败保留低细节，切换模式后可重试。

## 仍未验证

真实iPhone/Safari、Android GPU/FPS、热机/弱网/长时间浏览没有实机回执。模型层的面数和调用数不是整页FPS，MapLibre底图、像素密度与标签成本仍需计入。米制高度、部分中庭/立面/楼梯/入口尺寸仍为各原稿注明的视觉近似，不能解释为实测楼高或已核验室内信息；原照片公开复用许可/年份/原URL仍待补。

本机`next dev`沿用已有Workers初始化失败（`miniflare-email-store: CreateDirectory 拒绝访问`），因此采用`npm run build`和`npm run start -- --port 3026`验收。生产本机没有Workers/D1绑定，访问统计等既有接口返回500/503；本轮地图、模型、地点和本地步行功能实测可用，不据此宣称AI、账号等后端可用。没有远端部署、改D1、调用收费模型或扩大其他建模范围。

如需回退此批集成，可将catalog的`approvedForMap`设为false，保留南7原有路径及2D地图；资源和原模型稿仍可追溯。
