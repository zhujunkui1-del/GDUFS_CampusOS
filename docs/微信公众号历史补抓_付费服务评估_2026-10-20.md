### 次幂价格的适用边界

4,050 元只来自 `81 × 50 元` 的算术计算，条件是各号只取同一年度内的区间，不代表已确定报价或全额预算。官方导出样本是其他账号的 2022 年数据，确有原文链接和发文时间，**无正文列**。因此不能先买目录，再默认正文已包含或可通过当前被阻止的微信页面取得。

### API 价格的适用边界

Wellbyte 公开计价基准为 1 credit=US$0.001，页面列注册赠 500 credits，当前充值规则为 USDT-TRC20，并有网关及链上费用。文档的历史端点按成功请求计费；**不能将一次请求当成一篇文章或一个账号的完整历史**。其定价页曾出现人民币/支付宝询价提示，但计费正文仍写仅支持 USDT，其他支付方式和最低充值需要正式确认。[定价](https://www.wellbyte.net/zh/pricing)、[计费](https://www.wellbyte.net/zh/docs/billing)。

按上述基准，目录费用模型为 `0.078 × 成功目录请求数（美元）`，正文 V1 为 `0.030 × 成功正文请求数（美元）`，未包含手续费、折扣或其他接口。示例核验预算若限定为 2 个目录页 + 2 篇正文，名义为 216 credits / US$0.216。它只用于未来小样方案计算，**本轮没有注册、扣赠额或发起该请求，也不能用这个小样证明已到 7 月边界**。

Wellbyte 参数表要求表单格式，但页面生成的 cURL 使用 JSON；响应字段字典待补。后续真实接入前还需确认请求格式和日期结构。其示例标称采集日为 2026-09-23，是供应商样本，不是本次目标号实测。

Just One API 的公开使用指南说明服务自身 token 鉴权，具体价格需登录控制台；不能把旧博客或其他接口价格套用到历史/正文端点。[使用指南](https://docs.justoneapi.com/zh/usage)。
