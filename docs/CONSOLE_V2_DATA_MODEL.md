# Console V2 数据模型

只增量扩展现有权威。来源关联/运营证据、同步覆盖/next_sync_at放knowledge_sources。全局配置为单行版本化控制对象，命令继续原console_commands（job控制对象作用域）、审计原console_audit_logs，不另建文章/审核/采集任务权威。

来源—文章沿原knowledge_documents.source_id和document_origins多出处；日后移除一个来源不物理删除其他来源支持的文档。采集仍ingestion_jobs/steps/租约/fence，来源暂停与策略版本变更拒绝迟到提交。

新增职责分阶段：全局引擎配置/实测存储样本；来源级自动发布政策/内容检查/系统主体；版本正文按内容修订去重、原业务快照可解析引用且旧快照不改；白名单、清理计划/成员/墓碑；runner作用域凭据与心跳。系统身份复用console_admins增加principal_type/capability，不签发人类Console会话，权限仅指定动作，不读取学生表。

不重建现有表、不关闭外键。全局策略和清理控制沿现有命令事务/CAS，独立职责表不复制文章。原版本存在fetch/evidence复合外键，因此永久清理优先清正文/片段和大版本载荷，保留最小文档/快照墓碑及许可/审计/获取证据；不强删父行破坏FK。

V2-B/C增量：0015来源自动发布政策、系统主体、当前修订原文证明、完整性检查、发布凭证、按修订复用的载荷；0016保护、清理计划/对象/原子复查和墓碑。68业务表。未重建旧表、未修改原数据、未关闭外键。清理仅移除允许的大对象，复合外键父记录保留。

## 最终增量（0014–0022）

| 迁移 | 职责 | 数据风险 |
| --- | --- | --- |
| 0014 | 来源双事实治理、全局设置、真实存储采样 | 原有来源标志不改，不推断运营事实 |
| 0015 | 系统主体、源级发布政策、检查/证明/发布凭证、修订载荷 | 旧快照保留，既有撤回初始化保护 |
| 0016 | 白名单、清理计划/成员/原子复查/墓碑、导入截止 | 不执行真实清理，不改私人数据 |
| 0017 | 受限runner令牌、operator来源作用域、预算/调度防护 | 令牌只保存hash，系统不能登录人类会话 |
| 0018 | 公开查询复验策略有效期与当前修订检查 | 仅替换view/guard，失效内容不可继续引用 |
| 0019 | 来源阻断与全局暂停时拒绝领取/迟到提交 | 不改旧记录 |
| 0020 | 多出处人工导入证明、历史URL略过观察、维护边界/所有权 | 仅子表/守卫，不另建文章或任务权威 |
| 0021 | 人工退回/拒绝保护 | 不改历史审批，阻止自动重试翻案 |
| 0022 | 管理员直接启停、元数据导入与永久白名单 | 不改来源启用值/历史证据/文章/私人数据；已有active保护转永久+历史豁免，旧值在命令审计中保留 |

共72张业务表（另有SQLite内部表）。所有迁移按顺序运行，空库/有旧数据升级/失败事务回滚/FK与原字段逐值比较见 `verification/console-v2/database-upgrade.json`。新修订正文在console_revision_payloads中只保存一次，审批/发布快照引用它；旧内联快照不被批量改写。

来源—文档继续使用主来源和document_origins。新发现来源不能凭关联关系取得原文修改权限，operator修改既有文档必须具有原主来源及目标来源作用域。跨来源同URL但标题/日期/有权保留的正文不同会安全冲突，交原来源复核，不盲目合并不同年份或机构。

清理保留父文档、最小版本、许可、审计、外键证明；永久清理只移除允许的大对象。墓碑阻断旧任务；显式历史豁免与解除墓碑不撤销原来的人工拒绝/撤回。新增skip观察仅保存URL/日期/原因，不保存被拦截文章正文。

0021另保存人类审核否决的修订/hash，分析新修订仍需人类明确解除此前否决；不把重新抓取当新审批。明确的人工撤回在清理/白名单恢复中保留。D1当前仍72业务表，0021仅新增控制字段和守卫。

0022不新增业务表。enabled为业务状态权威，operating_status仅在直接启停时同步active/closed；旧枚举和核验字段保留兼容、来源列表不再据其隐藏实际enabled。白名单API将active写入统一为expires=NULL/history_exempt=1，移除统一解除保护/豁免。行政操作说明由服务端生成；不伪造原文发布时间、关联证据或转载许可。人工导入缺少expectedVersion时读取当前版本，manual_item_guard仍事务检查，明确传入旧版本仍拒绝。可信registryMetadata标志由服务端验证admin及无正文条目生成，不能从HTTP自行授予；完整正文仍复验许可版本和撤销。
