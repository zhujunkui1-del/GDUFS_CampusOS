# Console V2 自动发布政策

默认没有任何来源自动发布授权，不把4个旧enabled或3篇历史人工批准推断为系统授权。管理员预先批准来源级用途、有效期、规则版本和默认正式分类后，固定系统主体才可发布。采集器/模型不能传approved/admin或构造系统身份。真实三篇已撤回内容保留撤回保护，不因升级或作者变更自行复活。

确定性标题/许可内文本分类、简短标题说明、显式时间证据先于发布。普通公告/政策不要求活动时间；讲座等原文应有时间的内容缺证据入审；日期精度不填时刻，相对时间无锚点unknown。许可不满足直接阻断，未知但可补录的必需字段入异常队列。正文抓取失败与可发布metadata-only区分。

通过检查绑定当前内容修订/hash、业务版本、来源和政策版本；原子受限自动发布写原版本/审计/outbox。源更新覆盖此前人工修正但保留字段差异/旧版本；304/失败/未变输入不能覆盖可靠人工内容。取消/改期或无法确认的新版本撤销旧公开门禁，并使关联事件待核、索引失效。未开发雷达或RAG，不能宣称已有这些前端消费者。

统计按真实处理记录计算，隔离夹具和真实来源分开；真实授权/运行分母0时N/A，不给虚构自动发布率。
