# /agent 工作流观察界面｜2026-11-15

## 已发布

入口：https://gdufs.zhiyuapp.site/agent 。独立于校园地图布局，采用可拖动/缩放画布、节点详情、测试运行、事件记录和JSON导出。不会自动发起模型生成，需用户点击运行。页面只显示自己在此发起的本次请求，没有全站聊天/运行列表，不查询其他用户会话。

这是现有自研Agent的观察界面，未重新接入Dify，也不是可拖拽修改执行逻辑的DAG编排器。画布连线表示可能连接；节点状态、计时和数据来自实际执行事件，不能把连线都看作本次必经路径。布局拖动只浏览画布。

## 真实代码映射

- 用户输入、会话与边界、意图分流：原chatResponse会话验证、输入规则和contentIntent/queryPlan。
- 建筑资料匹配：原buildingEvidence读取已有地点/管理员简介；匹配完成且结果0不等于没有执行。校区或禁用路径跳过会明确标记。
- 活动检索：buildingAssistantProfile内部真实readCalendar，以及search_campus_events调用。保留窗口、地点、数量与原文入口。
- 文章RAG：真实search_campus_knowledge结果，包括正文/片段、公开状态、来源和指标。查询成功不等于命中足够证据。
- 地图工具、外部搜索：原Skill执行器发出的tool.started/finished及其参数、结果、耗时，不造工具结果。
- 模型调用：观察已有ModelClient调用；返回阶段、工具选择、字数和Token等结构化结果，不返回原始系统提示词、完整聊天上下文、HTTP凭据或隐藏推理。模型名为本次初选配置；底层HTTP重试/供应商回退不逐次展开。包装对象为请求局部副本，不修改可复用的模型运行时对象。
- 地图执行回执：观察原等待回执逻辑；没有确认时显示“未确认”，保持原预算/等待方式，不模拟成功，也不在本页挂载地图来执行动作。
- 表达与引用、输出：原处理阶段及原始问答终态。运行完成仅表示本轮返回，不保证每条陈述都正确；静态规则回复/复用也可由终止事件确认输出。

## 协议与隐私

界面直接使用原POST /api/agent/chat，添加X-CampusOS-Workflow:1。观察事件放在兼容的artifact.ready.payload.workflow内；普通聊天不增加观察数据。准备阶段在SSE连接建立后回放实际时间戳，后续阶段即时推送。原类型校验、身份、主体所有权、同源、取消、配额和证据门禁保留；不新增数据库表或历史扫描接口。

数据仅限当前请求的输入与原已授权的公开检索/工具结果。源码配置密钥、原始模型请求报文、其他账号资料和留言附件不进入画布或导出。导出由用户点击触发，保存当前问题、回答、节点、事件和指标。不向模型增加“解释自己的工作流”调用。

## 范围与未完成项

本轮只提供观察、自己测试、数据查看及导出，不提供编辑流程、发布节点配置、查看别人聊天或全站性能监控。真实地图执行发生在地图页面；本页无浏览器定位或地图实例。实体手机未连接，当前移动端验证为浏览器视口。现有地图成功话术与未确认回执不一致的问题记录于BLOCKERS，本轮不改变其业务控制；借阅资料命中充分性也不能由一个节点“查询完成”代替质量判断。
