# S3-B 首批五个官网｜只读可访问性、解析与权利审计

日期：2026-10-17（Asia/Shanghai）。范围：学校官网、学工、后勤、团委、图书馆各1个公开栏目、1篇详情。依据[冻结基线](../../S3_0_ARCHITECTURE_BASELINE.md)及本轮负责人授权，完成兼容性修复后继续S3-B；本报告本身不启用来源、不写D1、不部署。

[精简HTTP与规则证据](../../verification/s3-b/sources/http-audit.json)只含状态、URL、时间、字节/hash、缓存头、选择器和短日期证据；未保存第三方文章全文、图片或附件。

## 1. 方法和实际结果

使用独立的只读本地研究脚本，User-Agent明确标识CampusOS审计，TLS证书校验开启，重定向手动处理，无重试。总计**20次GET**：每站robots、主页、栏目、详情各1次；全部请求起始时间之间至少**10.001秒**。单响应上限2MiB，未触发上限。请求Wall Time约1041–1380ms，不是Cloudflare CPU测量。

| -------------------- | -------------------------- | --------------------------------------------------------------------------- |
| robots               | 5站均404                   | 没有观察到robots规则；不是全文采集、镜像或外部模型处理许可                  |
| 主页/栏目/详情       | 各5个HTTP200，共15页       | 无验证码、登录挑战、403或跳转；仅本次单样本，不代表长期稳定                 |
| 标题、原始发布日期   | 5个样本可识别              | 时间来自文章头部，不能取正文或推荐区第一个日期                              |
| 正文文本节点         | 4个样本大于0，1个为0       | 只证明有文本；**未证明4篇全文完整**，海报/获奖名单图片未读取                |

未追加条款页访问，未进入需要认证的学校系统，未尝试所有栏目或全站爬取。五个站均可作为**受控、仅元数据**Connector候选；自动化启用仍需管理员对精确栏目、用途和频率作许可判断并记录。不存在“HTTP200就自动标允许全文”的结论。

## 2. 机构归属和版权判断

五个入口均位于学校`gdufs.edu.cn`的精确HTTPS域名，主页有对应机构标题/品牌；团委站标题为“团学时空”，导航明确存在团委概况、团委简介和校团委学生部门。这构成学校/机构官网的公开证据，不把同名自媒体当官方，也不代表校方已授权CampusOS转载。[学校官网](https://www.gdufs.edu.cn/)、[学生工作部](https://nstu.gdufs.edu.cn/)、[总务后勤部](https://hqc.gdufs.edu.cn/)、[校团委](https://youth.gdufs.edu.cn/)、[图书馆](https://lib.gdufs.edu.cn/)

学工和后勤页面含版权所有/All Rights Reserved；其余本次观察页未发现可覆盖全文复用的明确许可。不把“未看到禁止”记为“取得授权”。本轮建议：保存必要标题、链接、来源机构、原始发布日期、抓取时间、HTTP缓存标识和解析状态；原文正文仅作内存结构核对，权利未确认时不持久化全文，不送外部模型，不镜像图片/附件，不公开逐段复制。活动名单/联系方式等个人字段不因公开网页存在而无差别收录。

robots证据：[官网](https://www.gdufs.edu.cn/robots.txt)、[学工](https://nstu.gdufs.edu.cn/robots.txt)、[后勤](https://hqc.gdufs.edu.cn/robots.txt)、[团委](https://youth.gdufs.edu.cn/robots.txt)、[图书馆](https://lib.gdufs.edu.cn/robots.txt)。本次均为404，状态和时间见JSON，不假设未来始终不存在。

## 3. 可实现的五个独立Profile

所有profile按**精确host + 栏目详情路径**白名单工作。发现可使用`a[href]`再以如下路径正则筛选、去重；不能只取页面第一个`/info/`链接，侧栏会混入别的栏目。标题统一可用`head > title`去除已验证的本站后缀；正文和日期每站独立配置。日期字段限定标签或局部节点，匹配必须唯一，缺失/歧义返回unknown，不使用全页首个年份。

### 3.1 学校官网：热点讲座

- 精确host：`www.gdufs.edu.cn`。
- [栏目入口](https://www.gdufs.edu.cn/xkky/rdjz.htm)：HTTP200。
- 详情路径：`^/info/1005/[0-9]+\.htm$`；[本次详情样本](https://www.gdufs.edu.cn/info/1005/265076.htm)：HTTP200。

## 4. 给实现阶段的约束与下一步

1. **时间**：原始published_at含精度，fetched_at是真实请求时间，source_updated_at没有语义证据则null；HTTP Last-Modified另存缓存元数据，系统updated_at仅表示记录更新。日期型原文不补00:00或23:59；有时分秒且无时区时按已声明的中国机构本地时间策略处理。
2. **版本**：此处HTML SHA只是审计响应指纹。实际content_revision/input_hash应针对规范化有权保存的输入，不因站点访问数/导航变化重复生成文章修订；ETag条件请求、原文修改和幂等入库仍须正式实现后测试。
3. **权利/审核**：默认metadata-only。公开文章可访问、文本可解析、后台审核批准、公开发布/进入索引是不同里程碑；本报告后三项均为0。没有权利时不把全文先塞D1再说“以后审核”。
4. **请求约束**：本研究已用20次请求并停止。实现后的真实入库验证需重新明确低频小批次预算，复用此次选定URL，不扩大到220源；403/429/验证码/robots新限制即暂停，不能重试风暴或规避。
5. **实现检查**：先以隔离HTML夹具验证精确栏目发现、日期唯一性、海报空正文、旧置顶、导航PDF排除和多事件分离。受控runner在本地做请求/解析，每步D1提交前重验来源许可、版本、任务lease/fence与取消；Workers普通HTTP不承载整站解析/批量模型流程。
6. **未验证**：全部分页、304条件响应、HTML变化增量、正文完整率、真实入库/审核/发布、长期频率政策、Cloudflare CPU与真实手机均不由此报告宣称通过。没有调用Dify或DeepSeek。
