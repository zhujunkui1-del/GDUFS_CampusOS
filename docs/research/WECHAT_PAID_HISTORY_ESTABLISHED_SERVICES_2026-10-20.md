# 微信公众号历史数据服务公开评估：新榜、西瓜及次幂补充候选

核验日期：2026-10-20（北京时间）。本记录只使用供应商自己的公开网页、官方帮助及其公开样本；没有注册、购买、付款、发送咨询或调用数据业务 API，没有请求微信或微信读书页面，没有读取现有凭据。

## 1. 当前结论

历史数据“按号、按时间回采并导出”是有公开产品依据的收费服务形态。其中，西瓜官方帮助有直接的时间范围回采说明；新榜有较旧的同类产品说明，但目前的具体交付、字段和价格仍需供应商确认。两者均未取得“广外就业中心”的样本，也未证明 81 个账号已收录。

额外发现次幂数据公开的按年按号报价及可下载 Excel 样本，适合询价对照；样本能证明其目录交付格式，不证明目标账号覆盖，也不证明能交付正文。

**现阶段可进入单号样本与正式报价核验；没有一家已被本轮验证为可直接购买后完整补齐全部 81 个账号。**

## 4. 各家证据及限制

### 4.1 新榜：有官方历史产品依据，但不要引用旧促销作当前承诺

2017-07-04 的官方文章描述了按公众号 ID、多个账号及时间段回采，结果可导出 Excel，表格附每篇文章链接，正文用语包含图文内容。这说明产品路线确曾存在，不能单凭该旧文判断 2026 年仍原样交付。[N1]

2024-04-29 的小数林试用文章要求完善信息、添加数据经理、申请限时名额。本轮没有申请；活动日期较旧，不能声称当前可免费获取单号历史。[N2]

当前官网仍列有定制 API 服务，但未获得满足本任务的可读参数表、当前计费表、全文许可和目标账号查询结果。普通“号内搜”宣传也不能替代可批量交付目录与正文的合同。[N3]

### 4.2 西瓜：时间回采依据直接，但历史覆盖与使用边界要单独确认

官方帮助说明可以在定制化服务中输入公众号、选择时间段并付费取得文章数据报告。帮助页所举日期为 2018 年，需核对当前规格。[X1]

“近 24 个月历史推文”帮助正文明确写着当时是 **2019 年 5 月 17 日**，不能把搜索引擎近期抓取日期解释为 2026 年的新承诺。[X2]

另一官方帮助说明：未收录号可通过文章链接加入，之后自动更新；往期运营数据要另行付费抓取。因此“成功找到公众号”不代表从成立以来历史都齐全。[X3]

最新用户协议页面标注 2026-08-28 更新、2026-09-05 生效。条款包括：未经书面许可的程序取数限制、数据境外转移限制、云端访问/第三方使用限制，以及平台信息完整性不保证。应采购供应商正式交付的数据及明确用途许可，不能把普通会员页面自行抓取接入 CampusOS 云端。[X5]

### 4.3 次幂：有公开单价与静态目录样本；正文仍未证实

公开导出页显示：按日期范围及账号计费，50 元/年/账号，不满一年按一年计，付款后预计 10—60 分钟可在记录页下载。按页面单价计算，若 81 个账号各取同一不满一年的区间，算术结果为 **4,050 元**；这是未取得合同前的粗估，不是报价，也不包含已证实的正文服务。[C1]

本轮只读下载其公开“导出示例”ZIP，在内存解析 XLSX 的表头与前两行，没有执行文件。ZIP 中只有 `辉哥奇谭20221202.xlsx`，表头：

`发文时间、标题、作者、发文位置、原创、阅读量、在看数、点赞数、赞赏数、链接`

样本实际含正常格式的原文长链接和发文时间；**无正文列**。它是 2022 年其他账号的静态样本，不能证明目标账号现有覆盖、日期准确性或持续可用性。[C2]

官方 API 服务页展示 AppID/Secret 换取 token 的对接路线，并链接开发文档与报价。本轮只读打开文档页面，网页工具未渲染正文；没有开通或发出任何业务 API 请求。[C3]

其用户协议保留知识产权及第三方内容责任等限制，没有足够依据把历史目录购买等同于第三方文章全文再发布许可；正文下载、内部保存、索引与对外展示分别列入待确认条款。[C4]
