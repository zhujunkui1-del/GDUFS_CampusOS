# 大会堂 · 首版2.5D / 3D

2026-10-25。负责人授权本栋制作，并提供“**4层楼高**”的体量参考。当前为独立视觉评审稿，尚未接入正式地图。

## 查看与文件

在项目根目录执行：

```powershell
node scripts/serve-auditorium-preview.mjs
```

打开 <http://127.0.0.1:3016>，可切换2.5D/3D、整体/正面/侧面/俯视，拖动旋转与滚轮缩放。服务只监听本机，不提供原参考图片。

| 文件                                                                      | 用途                                                                           |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `auditorium-2.5d.glb`                                                     | 无立面装饰的白模，保留弧形大屋顶、前方台基与两侧低翼院落                       |
| `auditorium-2.5d.geojson`                                                 | 分部体量、院落内环及高度参数；主厅height是最大外包络高度，实际曲面见GLB/生成器 |
| `auditorium-3d.glb`                                                       | 红砖侧墙、弧形金属顶、白色柱廊、采光雨棚、窗墙及低附楼                         |
| `design.json`                                                             | 可编辑参数、负责人高度描述及7张原参考图SHA256                                  |
| `manifest.json`                                                           | 稳定ID、原轮廓、WGS84锚点、局部变换、资产SHA与复杂度                           |
| [build-auditorium-model.mjs](../../../scripts/build-auditorium-model.mjs) | 可编辑程序建模源，重新生成命令为`node scripts/build-auditorium-model.mjs`      |
| `asset-checks.json`                                                       | 来源、分部外环面积、零纹理、局部坐标和旧模型哈希核对                           |

普通应用启动/构建不重新生成模型。

## 确认信息与近似项

- 绑定固定地图`s1-2026-10-14.2`的`osm-way-307250997`，地点名称沿用“大会堂（教工活动中心）”，原点为WGS84`[113.39157995,23.06922125]`。生成器将原轮廓转换为局部东/上/南米制坐标，模型保留显式坐标框架节点。
- 负责人说“4层楼高”，本稿登记为**外部体量描述**。未取得室内层图，不宣称会堂内部实际分成四层；前厅三组大窗带来自照片观察。原OSM无`height/building:levels`，未回填。
- 屋檐17.5米、拱顶起伏4.8米（最高约22.4米）、入口红色翼墙18.7米、左低附楼7.6米、右廊5.2米、台基1.8米均为视觉设计参数，未实测。层高和米制总高仍待核对。
- 主厅、前方台基及左右翼四个分部外环合并后与源外边界保持一致，面积误差小于0.0001平方米。源OSM没有两侧院落内环，照片近似的两个显示洞口另记`photo_informed_visual_approximation_not_source_GIS`；没有改正式GIS或路网。
- 保留大跨度弧顶及前窄后宽的阶梯轮廓、弯曲红色侧墙、白色圆柱、雨棚采光格、角部玻璃与两侧低翼。屋面少量接缝、机电盒、窗格和台阶是简化显示；不逐条复制波纹、不制作室内、座位、树木或真实导航入口。
- 六张立面/鸟瞰图留在原文档包；Downloads的俯视图原像素存文档包`assets/model_references/auditorium-v1/大会堂俯视.png`。文件名数字不作建筑依据。原发布链接、年份及照片公开再利用许可未补齐，原图仅内部参考，不复制到`public/`、预览图片端点或GLB纹理。
