## 两种模式

2.5D只有三组高低白色体块和浅灰屋顶帽，沿用南北苑的 `#e8e5dc` / `#d5d2c8` 材质，不含窗户、栏杆或屋顶构架。

3D表现浅色6层主楼、蓝灰窗带的3层对面楼、红色2层拐角、平屋顶和6层主楼两端的镂空构架。主楼下两层窗高与上四层窄窗带区分，院侧增加简化走廊檐线/栏线，端部有竖向楼梯核心窗。屋顶构架最高约22.235米。所有米制尺寸、开窗节奏和设备均为显示近似，没有室内或已核验导航信息。
