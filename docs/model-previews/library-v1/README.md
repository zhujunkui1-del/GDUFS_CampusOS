# 图书馆 · 首版2.5D / 3D

2026-10-24。状态：**单栋独立视觉评审稿，尚未接入正式地图**。负责人本轮授权开始图书馆建模，并确认最高主体为6层。没有批量制作其他建筑。

## 查看与文件

```powershell
node scripts/serve-library-preview.mjs
```

打开 <http://127.0.0.1:3014>，可切换2.5D/3D、整体/正面/侧面/俯视，拖动旋转、滚轮缩放。仅监听本机，原参考照片不通过服务提供。

| 文件                                       | 内容                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------- |
| `library-2.5d.geojson`                     | 2.5D的分部体块参数；含主楼中庭与低附楼，仅供显示评审                    |
| `library-2.5d.glb`                         | 同一2.5D体块的独立预览资产                                              |
| `library-3d.glb`                           | 轻量立面、柱廊、遮阳板、屋檐、圆形玻璃屋顶构件及中庭                    |
| `design.json`                              | 可编辑的楼层、比例、预算与6张参考图SHA256                               |
| `manifest.json`                            | 稳定ID、源轮廓、坐标变换、资产SHA256及实际复杂度                        |
| [build-library-model.mjs](../../../scripts/build-library-model.mjs) | 可编辑程序建模源 |

重新生成：项目根目录执行`node scripts/build-library-model.mjs`。生成器只写本评审目录，不在应用启动/构建时运行。

## 已知事实与近似项

- 绑定`osm-way-307250998`，使用固定地图`s1-2026-10-14.2`的原外轮廓和WGS84锚点`[113.39131405,23.0680465]`。主楼/附楼的分部外环合起来保留源外边界。
- **6层由负责人明确确认。** OSM原way没有`height`或`building:levels`，没有把负责人确认或模型参数写回OSM/校园地物表。
- 主楼的六个楼层区间为1–5.8、5.8–10、10–14.2、14.2–18.4、18.4–22.6、22.6–26.8米；这些是**视觉设计参数**。屋面27.25米、顶部构件30.65米、附楼14.4米均未实测，不作为建筑事实或导航数据。
- 保留照片中开放的切角中庭。源OSM外轮廓没有中庭内环，本稿的中庭、前后分区、柱网、开间、遮阳板数量、屋顶设备和附楼分界为照片参考近似，不声称实测。中庭从底到顶留空，所有屋面开洞。
- 照片观察对应陶红外墙、四柱入口大凹槽、竖向遮阳片、宽银色屋檐、侧面五组竖窗、折角百叶面、圆形玻璃构件。屋顶设备/光伏仅少量几何概括，没有室内、人物、树木、逐砖纹理或逐片设备。
- 文件名后数字没有用于层数、尺寸或照片顺序。参考图原像素仅保留文档包，水印作者/原链接/拍摄年份及照片公开使用许可未补全；本稿不再分发原图，也不使用照片纹理。
