# 院系办公楼 · 首版2.5D / 3D

2026-10-25。负责人授权本栋制作，明确“4层楼高”。当前为独立视觉评审稿，尚未接入正式地图。

## 查看与文件

在项目根目录执行：

```powershell
node scripts/serve-faculty-office-preview.mjs
```

打开 <http://127.0.0.1:3019>。支持2.5D/3D、整体/正面/侧面/俯视、拖动旋转及滚轮缩放。服务只监听本机，不提供原参考图片。

| 文件                                                                              | 内容                                                                        |
| --------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| [faculty-office-2.5d.glb](faculty-office-2.5d.glb)                                | 白模，保留E形主体、两处庭院开口、坡顶与入口体量                             |
| [faculty-office-3d.glb](faculty-office-3d.glb)                                    | 红白封闭窗墙、石色柱、灰坡顶、角塔、山墙门廊和弧形台阶                      |
| `faculty-office-2.5d.geojson`                                                     | 原源环及显示门廊参数，height为最大外包络，实际坡顶见GLB/生成器              |
| `design.json`                                                                     | 负责人高度描述、可编辑米制参数、屋顶模块及4图路径/字节/SHA                  |
| `manifest.json`                                                                   | 稳定ID、WGS84原点、原轮廓、局部坐标、模型SHA及复杂度                        |
| [build-faculty-office-model.mjs](../../../scripts/build-faculty-office-model.mjs) | 可编辑程序建模源；重新生成执行`node scripts/build-faculty-office-model.mjs` |
| `asset-checks.json`                                                               | 源轮廓、庭院采样点、图片/模型哈希及旧模型资产保持核对                       |

应用普通启动/构建不自动重新生成或发布模型。

## 依据与显示近似

- 稳定ID`osm-way-307437431`，地图版本`s1-2026-10-14.2`，WGS84原点`[113.39555615,23.065696799999998]`，局部东/上/南米制。原E形外轮廓完整保留，两处院落是源凹口，不补成封闭楼体或虚构内环。
- 负责人“4层楼高”为外部体量依据，立面显示四组窗带；没有制作/核验室内四层平面，原OSM没有高度/楼层标签，也未回填。
- 楼层边界0.55/4.05/7.55/11.05/14.55米、屋檐14.75米/主坡顶17.85米、角塔最高18.1米、门廊檐口10.7米/脊13米和台阶0.6米均为视觉设计参数，未实测。
- 四个坡屋顶模块在离线生成阶段裁掉相交遮挡面，再裁切到原E形轮廓的显示屋檐缓冲，保留两处院落开口。主坡顶345个三角面；运行时只加载GLB，不运行屋面裁切。
- 封闭窗墙、红色窗间墙/窗下带、浅色立柱与石色下部、灰坡顶、角部小塔、山墙入口、拱梁和弧形台阶均来自照片概括。屋顶比例/拼接、门廊和轻型连接构件的位置/尺寸是近似；不逐瓦、逐砖或制作精细室内。
- 门廊、台阶、屋檐与角塔可能超出原底图轮廓，属于显示细部；两处轻型连接只画细柱/梁，不补新GIS障碍或导航边。建筑入口模型不当作已核验导航入口，原地点/路网/标签不改。
- 三张正面/鸟瞰照片留在负责人指定文档包；Downloads的俯视图原像素存文档包`assets/model_references/faculty-office-v1/院系办公楼俯视.png`。文件名数字无建筑意义，4图SHA见design.json。原发布链接、年份与照片公开再利用许可未补齐，原图仅内部参考，不进入`public/`、预览图片端点或GLB纹理。
