# B8学术报告厅 · 首版2.5D / 3D

2026-10-25。负责人明确授权本栋建模，并提供“**2层楼高**”的外部体量依据。当前为独立视觉评审稿，尚未接入正式地图。

## 查看和文件

项目根目录执行：

```powershell
node scripts/serve-b8-lecture-hall-preview.mjs
```

打开 <http://127.0.0.1:3017>。支持2.5D/3D、整体/正面/侧面/俯视、拖动旋转及滚轮缩放。服务只监听本机，原参考图片不通过预览服务提供。

| 文件                                                                                | 内容                                                                         |
| ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `b8-lecture-hall-2.5d.glb`                                                          | 保留弧形屏墙、浅坡屋顶、后部高体块和低前厅的轻量白模                         |
| `b8-lecture-hall-3d.glb`                                                            | 红墙、浅色主体、板缝、玻璃入口、门框、雨棚和简化台阶                         |
| `b8-lecture-hall-2.5d.geojson`                                                      | 原轮廓参考底座和显示分部参数；主体height为最大包络，实际浅坡见GLB/生成器     |
| `design.json`                                                                       | 可编辑体量、弧墙路径、预算和6张参考图路径/字节/SHA256                        |
| `manifest.json`                                                                     | 稳定ID、地图版本、源轮廓、局部坐标变换及GLB SHA/复杂度                       |
| [build-b8-lecture-hall-model.mjs](../../../scripts/build-b8-lecture-hall-model.mjs) | 可编辑程序建模源；重新生成执行`node scripts/build-b8-lecture-hall-model.mjs` |
| `asset-checks.json`                                                                 | 原轮廓/来源/模型校验和既有四栋资产保持核对                                   |

生成器不参与应用普通启动或构建。

## 事实、比例和来源

- 绑定固定地图`s1-2026-10-14.2`的`osm-way-651642991`，沿用已确认名称“B8学术报告厅”及WGS84原点`[113.3932707,23.06863825]`。局部坐标为东/上/南米制，并在GLB中保留显式坐标框架节点。
- “2层楼高”是负责人提供的外部体量描述。原OSM没有米制高度/楼层字段，本轮没有核验或制作室内两层布局。后部高体块按照片表现，不作为额外楼层推断。
- 主体屋檐7.05米、浅脊7.5米、红色屏墙8.9米、后部高体块10.6米/女儿墙10.95米、前厅5.6米、入口侧体块6.7米和台阶0.95米均为视觉设计参数，未实测。
- 原矩形轮廓完整保存在清单与低参考底座中，底座面积与源轮廓误差小于0.0001平方米。主体、前厅、后部高体块、入口侧体块和弧形屏墙是照片近似显示分部，不声称其并集等于已核验建筑分部GIS。显示构件可与底座重叠；原地点轮廓、障碍和路网未改。
- 保留弯曲红砖屏墙、浅色板墙、后部方形高体块、浅坡金属屋面、低玻璃入口、白色门框和雨棚。屋面接缝、设备盒和板缝为有限重复几何，没有逐砖纹理、精细室内或逐台机电。脚手架/施工残料不进入建筑永久模型，也不从文件名推断照片时间先后或当前施工状态。
- 五张立面/鸟瞰图保留在负责人指定文档包；Downloads的俯视图原像素复制到文档包`assets/model_references/b8-lecture-hall-v1/报告厅俯视.png`。六图SHA见design.json。文件名数字无建筑意义。原发布链接、年份和照片公开再利用许可未补齐，原图仅内部参考，不放入`public/`、预览图片端点或GLB纹理。
