# 友苑模型复核（2.5D白模修订）

## 2.5D样式修订

负责人指出友苑2.5D应与南苑、北苑采用同一种纯白体块。现用同一墙体色 `#e8e5dc`、屋顶色 `#d5d2c8` 和21米估算包络，只保留原GIS外轮廓、白色主体及浅灰屋顶帽；不显示窗、红砖、阳台、设备块或圆弧大厅。

此修订只生成和接入2.5D GLB，2.5D为168个三角面、2个材质。未写入或重建3D GLB。更新前后3D SHA256均为 `5013c5a98ccc949862573907e14005ea894664c9950558426793b7fd4a80e47e`，文件大小239,812字节。

## 3D样式及运行确认

3D仍沿用之前完成的立面模型：七层视觉估算、红砖核心、窗带、阳台栏线、平屋顶设备提示和浅圆弧大厅。2.5D/3D共用友苑同一个GIS定位与外轮廓。

更新后浏览器实载回执保存于 `output/playwright/youyuan-model-2026-11-12/capture-summary.json`：2.5D新资源HTTP 200；3D现有资源HTTP 200且哈希不变；平移/旋转后3D驻留数不变、失败0。

## 精度限制

7层和约21米仅为照片估算。地图没有友苑的实测内院、入口方位、背面和屋顶设备数据，不据此修改GIS或导航。
