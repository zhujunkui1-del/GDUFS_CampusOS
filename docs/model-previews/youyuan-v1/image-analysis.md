# 友苑影像分层观察（建模前）

参考照片：`assets/source_maps/广外地图/友苑.png`。卫星屋顶：`C:/Users/zhuju/Downloads/友苑卫星图.png`。`assets/source_maps/广外地图/粗略/n.jpg` 只用于了解地理相邻关系，不参与几何或坐标拟合。附件名后面的数字不作参数使用。

## 直接观察

- 对象是同一个外轮廓内相连的多翼宿舍楼群，整体显著大于单栋标准宿舍。正面视图可见一条长向主翼、至少两条转向翼、近中部另一条突出翼和室外相连平台。
- 立面反复出现浅色横向楼板/阳台、白色栏杆、灰蓝色窗，砖红色实墙和竖向核心筒把长立面分段。面上有大量规则重复的开间。
- 卫星图的边线呈阶梯状折转；屋顶中庭/开敞间距和连接体量至少分成两处，走廊/小翼把不同翼楼连成整体。主屋顶以平顶为主，若干端部有较深色设备或屋面盒体。
- 正面近中央、朝向内院的一处可见圆弧形门厅/雨棚体量。它与楼体连接；图像不能证明它是独立结构或精确直径。
- 正面视图可数出的重复层带约7层；局部白色屋面设备/凸起是屋顶附属体，不据此增加楼层。

## 图形与空间关系

按3D对象空间描述：长主翼围合住院内的开敞区域；端部及中间竖向核心墙体附接主翼；转向翼与主翼在转角处连接；内侧连接平台和圆弧门厅朝向内院。来源仅提供整体真实外环，不提供各翼独立ID或实测分缝，因此所有翼、核心筒、门厅均是一个Youyuan显示模型的子部件。轮廓用既有WGS84来源Way，绝不从照片重绘地图足迹。

## 材质和局部识别特征

直接可见：暖红砖色实墙、象牙白/浅灰陶瓷面层、灰蓝玻璃窗和偏白金属栏杆；层板/窗带水平重复，砖红竖向核心形成节奏，圆弧门厅与开敞内院是辨识特征。推断：红色墙为粗糙哑光砖/砖贴面，浅色墙为细颗粒哑光陶瓷，玻璃仅做不透明/低透明度色片示意，栏杆为涂装金属。这些推断用于程序材料，不生成照片纹理。

## 不确定项

卫星图分辨率有限且树冠遮挡部分底层；单张正面照片不能确定背立面、各翼长度的标定值、实际层高、朝向北的立面、幕墙后室内结构、设备盒高度及真实入口连通。大体量楼群只标出能辨认的约7层重复层带，米制楼高和院落细分仍为视觉估算。OSM轮廓不含可视为测量的内院/各翼界线，不把影像推定的开敞空间写回GIS或导航事实。
