# 师苑1—4栋地图模型复核

## 实现

- 四栋分别对应校园GIS的既有Place ID，使用各自原始外环，不做新的组合地点或室内导航几何。
- 2.5D是纯白主体与浅灰屋顶帽，沿用南苑/北苑白模样式。
- 3D使用六层视觉估算，增加灰蓝窗带、暖橙/红色竖向构架、阳台栏线和简化屋顶块；二饭只作为立面参考图的背景，没有加入模型。
- GLB不含照片或纹理，颜色及立面构件间距是视觉近似。

## 估算边界

GIS没有楼层/高度字段。六层、约18米根据参考立面估算；精确高度、真实入口、屋顶设备与楼梯核心尺寸未测量。卫星图用于理解四栋相对分布，不据此添加内院或路线数据。
