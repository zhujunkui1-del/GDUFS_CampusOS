# 艺术楼 · 首版2.5D / 3D

2026-10-24。负责人授权本栋建模，并确认**主体5层**。当前是独立视觉评审稿，尚未放入正式地图。

## 查看和编辑

项目根目录运行：

```powershell
node scripts/serve-art-building-preview.mjs
```

打开 <http://127.0.0.1:3015>。支持2.5D/3D、整体/正面/侧面/俯视、拖动旋转与滚轮缩放；静止时停止重绘。服务只监听本机，不提供原参考图片。

| 文件                                                                          | 用途                                                     |
| ----------------------------------------------------------------------------- | -------------------------------------------------------- |
| `art-building-2.5d.geojson`                                                   | 主楼、低附楼的2.5D体块参数，仅供显示评审                 |
| `art-building-2.5d.glb`                                                       | 同一2.5D体块的独立预览模型                               |
| `art-building-3d.glb`                                                         | 轻量3D模型，含红白立面、竖肋、弧形采光顶及架空附楼       |
| `design.json`                                                                 | 可编辑层数、层间距、显示高度、预算及6张原参考图SHA256    |
| `manifest.json`                                                               | 稳定ID、原始轮廓、WGS84锚点、坐标约定及资产SHA256/复杂度 |
| [build-art-building-model.mjs](../../../scripts/build-art-building-model.mjs) | 可编辑程序建模源                                         |
| `asset-checks.json`                                                           | 原轮廓、分部面积、引用/模型哈希及原资产保持核对          |

重新生成：`node scripts/build-art-building-model.mjs`。生成器只写本目录，不参与应用普通构建。

## 来源和近似边界

- 源为固定地图`s1-2026-10-14.2`的艺术楼`osm-way-1389970391`，锚点`[113.39281705,23.0693811]`，局部坐标为东/上/南米制。保留原弧形折段、开放院落和附楼轮廓。主楼/附楼分部外环合并的面积与源外环一致，误差小于0.0001平方米。
- **主楼5层是负责人明确确认。** 原OSM未提供`height`或`building:levels`。六张图文件名后的数字没有用于建模尺寸或层数。
- 主体楼层边界0.7、4.9、9、13.1、17.2、21.3米、屋面21.55米、女儿墙22.15米及低附楼11.8米均为视觉设计参数，尚未实测。最高通风构件约23.65米。附楼架空层3.8米也为近似，不把这些高度作为正式建筑事实。
- 开放院落直接保留源凹轮廓；没有补造闭合中庭内环。照片中内院景观、铺地、湖水和树木不作为建筑模型资产，也不生成导航通行信息。
- 根据照片概括红砖墙、白色窗框/竖肋、五层窗带、弧形玻璃采光顶、长条街面窗幕、低灰色墙体装饰方块和架空层。开间/构件数量、分部高度、屋顶服务体块与设备均为显示近似，没有精细室内和逐个空调。
- 五张正/背/侧面照片留在原文档包；Downloads的俯视图原像素另存文档包`assets/model_references/art-building-v1/艺术楼俯视.png`。原发布链接、作者/拍摄年份及图片公开再利用许可尚未补全；仅内部参考，原图不进入`public/`、预览端点或GLB纹理。
