## V2-D 交付边界（2026-10-18，最终实测以验收报告为准）

五个一级页面均使用真实D1 API；无假文章、假存储或假云端指标。总览支持来源/时间范围统计，新增按首个业务快照时间而非最后抓取时间计算。来源详情包含当前来源的任务和操作历史；旧入口仍兼容。来源10载体不压缩为5种，只有5个现有官网规则可自动采集。

人工导入支持原文核对与来源级自动策略，只有human admin能写原文核对证明。规范URL保留身份、年份、机构参数，去除UTM及微信展示跟踪；同一规范URL的匹配元数据复用原文章并增加出处，差异内容不凭标题合并、不覆盖其他来源的人工修正。未授权登录系统不属于自动Connector。

自动发布与异常审核均已实现：正常通知不要求活动字段；缺证据的活动转人工；拒绝/退回的文章不能靠重试、换源或简单改动自动翻案，原作者新修订可再次分析，仍需人工解除此前否决。人类明确撤回与保留清理保护互不替代。

清理预览/标记/执行为持久化小批次；网页仅在管理员明确发起后推进，可暂停或离开页面保存断点。API默认不允许永久执行，隔离内存测试才开启。真实preview始终仅dry-run，不以源码参数或网页参数开启删除。

实际调度由本地受控Node runner执行，每小时检查D1到期策略，默认每源24小时；有scheduled处理器但未开启Cron Trigger。电脑离线不能保证完成同步。20次网络预留/UTC日和10个web任务/UTC日保持不变，不宣称能以此预算自动更新全部220源。模型调用本轮0。
