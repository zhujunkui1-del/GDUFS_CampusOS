## V2-D 交付边界（2026-10-18，最终实测以验收报告为准）

五个一级页面均使用真实D1 API；无假文章、假存储或假云端指标。总览按全部来源展示实际统计，移除总览筛选表单；新增按首个业务快照时间而非最后抓取时间计算。来源详情包含当前来源的任务和操作历史；旧入口仍兼容。来源10载体不压缩为5种，只有5个现有官网规则可自动采集。

人工导入默认显示日期时间输入，留空仍未知；版本由服务端读取并在事务内复验，不再要求手填版本或原文核对勾选。管理员可直接登记启用来源的链接元数据；全文权限独立。规范URL保留身份、年份、机构参数，去除UTM及微信展示跟踪；同一规范URL的匹配元数据复用原文章并增加出处，差异内容不凭标题合并、不覆盖其他来源的人工修正。未授权登录系统不属于自动Connector。

自动发布与异常审核均已实现：正常通知不要求活动字段；缺证据的活动转人工；拒绝/退回的文章不能靠重试、换源或简单改动自动翻案，原作者新修订可再次分析，仍需人工解除此前否决。人类明确撤回与保留清理保护互不替代。

清理预览/标记/执行为持久化小批次；网页仅在管理员明确发起后推进，可暂停或离开页面保存断点。API默认不允许永久执行，隔离内存测试才开启。真实preview始终仅dry-run，不以源码参数或网页参数开启删除。

实际调度由本地受控Node runner执行，每小时检查D1到期策略，默认每源24小时；有scheduled处理器但未开启Cron Trigger。电脑离线不能保证完成同步。20次网络预留/UTC日和10个web任务/UTC日保持不变，不宣称能以此预算自动更新全部220源。模型调用本轮0。

## 负责人交互修订（2026-10-18）

覆盖上文历史阶段中的多状态、双事实必填、审核说明、限期保护交互。管理员一键启用/停运/软删除、批准/退回/拒绝、加入/移出白名单，审计自动生成动作说明；身份/角色/作用域、CSRF和版本冲突检查继续运行。软删除保留来源、文章和审计证据。

白名单统一永久保护并豁免历史导入日期，直到管理员移除；不自动恢复已撤回、取消或被清理的内容。无原因、期限、状态下拉或多选模式开关。搜索和多选同一组件，选择数量无UI上限，服务端每次最多处理5项。来源只搜显示名称，白名单文章只搜标题，禁止隐藏别名或内部编号造成无关匹配。

总览移除筛选、执行器凭据、日预算编辑及任务列表；执行器凭据移到来源同步详情的高级设置，原调度、预算、任务API和历史保持。审计日志只留一个标题。白名单选框18px、行右侧居中；移除按钮位于分页右端。五页标题统一600，正文/控件400；主要按钮蓝底白字、高44px、内容宽度，不横向撑满。
