- 退出/关闭导航：清除路线、地下段、定位引导段、起终点与选点状态，停止定位；旧异步镜头回调失效。重置路线仍允许在当前输入上重新规划。
- 设备起点：校内GPS点先用独立虚直线引导到同区最近可接入步道，随后实线走本地路网；在批准教学/实验区域内可直接穿行。虚线不登记为已核验道路，不跨水、不吸附地下边；跨区仍必经下沉隧道。定位、路由与进度测试使用公开北苑1栋/隧道坐标，不是个人实机定位截图。
- 教学B→实验C：新增负责人确认A—G连片可穿行区域，按源轮廓包络排除水面/其他建筑/校外构图；补齐桥西端与教学楼的实际几何连接。WGS84节点统一精度去重，避免同一落点生成两个不连接的节点。最短路约262米/3分钟，经语心桥，取代原约542米南侧绕行；未强行预设某一桥或手写距离。
- 镜头：公共入口统一600ms ease-out，由快到慢、可打断、支持减少动态，目标考虑搜索/导航/详情/AI的实际占位。删除布局resize跳转和重复pitchend拟合；用户地图选点保持视角。生产CSS会把600ms写成0.6s，旧parseFloat把它误当0.6毫秒；已按s/ms换算。浏览器逐帧测试验证连续位置与后段减速，而不是只检查声明参数。
- 手机规划成功后只显示距离/时间、开始/重置，路线步骤按需展开；增大可用面板高度，主操作完整可见，规划期间AI浮钮收起，开始导航后保留专注界面。
