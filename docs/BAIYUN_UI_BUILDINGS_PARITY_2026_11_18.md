# 白云山地图公共控件、详情与建筑管理补齐

2026-11-18，依据负责人七项浏览器批注实施。此前白云山单独实现页面，遗漏登录头像、留言、访问量和导航；搜索表单缺少大学城的toolbar布局，窄屏占满宽度；地点卡与建筑管理未共用现有资料链路。

## 实现

1. 两校区共用 `MapUtilities`：从同一AccountProvider读取登录头像/游客状态，复用原留言与访问量组件、接口和对话框。白云山搜索表单套用原map-toolbar，保留右侧两入口的位置，清空按钮使用原search-clear样式。
2. 白云山复用原 `PlaceDetails` 抽屉、手机拖动/展开/关闭/焦点恢复、导航终点操作及 `BuildingInfo` 简介/照片/活动模块。后台暂无资料时沿用真实空状态，不生成介绍或图片。公共建筑接口识别白云山ID，活动查询接受这些建筑ID；没有已关联活动时返回0，不伪造活动。此次没有扩展Agent的白云山活动定位或知识检索范围。
3. 建筑管理并入104个白云山具名地点，返回明确campus字段；顶部右侧使用与地图同一 `CampusSegments` 组件区分校区。搜索/建筑选项随校区过滤。原D1 building_profiles、图片上传、CSRF、管理员权限和审计复用，无新表/迁移。简介和照片按稳定OSM ID保存，同名跨校区不共用记录；原大学城体育分组规则保留。
4. 补回白云山导航键和同款路线面板。`prepare-baiyun-walking.py` 从既有两份固定OSM抽出699节点、744段/123条源way的校内步道图；原校内对象优先。保留原节点连接，排除源数据禁止步行/private/locked的段和节点，不猜测连接线。图书馆到第二教学楼的结果逐段验证均属于源边；校外/同一点和不连通情况明确失败。
5. 白云山导航支持起终点搜索、我的位置、交换、规划、步行跟踪、重置/关闭。显示距离按原路段长度、时间按步速估算；蓝线起止于路网接入点，不把建筑中心到路网的猜测直线画成已核验道路。GPS仅用户点击后请求、本页内存使用；过期/低精度/偏离路线不推进进度，关闭、切校区、卸载或后台停止watchPosition。不做跨校区步行，不增加3D。

## 验证

- 发布前对旧线上运行头像/公共控件用例，切到白云山后头像断言失败；原失败证据在 `before-ui.log` 和 `before-results/`。
- 全仓Lint、TypeScript通过；175文件/1236项单测通过。新增路线测试验证每段确实来自OSM图、校外拒绝；真实SQLite/D1适配器测试验证白云山目录、管理员保存、公共回读、大学城记录不受影响，原鉴权和图片测试保留。
- Edge/Chrome桌面与手机专用8项E2E分别通过；最终生产构建Edge8项通过。覆盖登录头像、留言/统计开关、515/1078宽度不重叠、统一详情、选择终点、规划/清路、后台校区/保存隔离。后台保存及登录身份在浏览器中使用隔离夹具，不修改真实线上简介/照片。
- 浏览器原生定位API在隔离授权/坐标模拟下验证：开始导航有1个watch，关闭后0个watch和0个路径点。这不是实机GNSS精度或现场可通行性验收。
- 公网Edge桌面/手机8项通过，真实公共建筑读取及活动查询200；第二教学楼/北校区图书馆返回campus=baiyun，活动查询当前返回0。后台写入线上未使用真实管理员账号作测试；服务器真实保存/鉴权和隔离UI路径按上述本地测试验证。
- 生产Worker构建、最终入口dry-run与1828个生成文件凭据净化扫描通过；旧大学城GIS、OSM地图、模型文件不变。
