# S1 本地地图、浏览器交互与名称修订验收

日期：2026-10-13。当前版本 s1-2026-10-13.6，87个校园地点。此报告记录本次修订；此前高德底图截图为历史状态。

## 实现与证据

- 经负责人明确确认，默认引擎切换至 MapLibre GL 6.14.0，本地 OSM 版本 `s1-2026-10-13.6`。首次地图加载无高德 SDK、底图、配置或坐标转换请求；在线查询/路线由明确点击触发。
- 当前底图4495个来源地物，原始2,487,983字节、gzip约464,964字节。周边用于透视和旋转的显示缓冲，校园业务/路线未扩大至周边学校。
- 默认朝北0°。旧代码横屏主动设90°已复现并修正；窗口变化保留用户视角。原高德页面只在内置浏览器核验，不能推断所有外部浏览器已通过。
- 新本地引擎接入过程中，真实 Chrome 测试捕获地图容器高度0（第三方CSS覆盖固定定位）和 worker URL 解析失败；用更明确的容器规则和同源、锁版本 worker 修正，未将此新问题当作旧版卡顿的全部成因。
- 真实投影校准总览；使用渲染前约束、允许倾角/任意朝向的保守地面视口包络、动态缩放下限，避免只约束地图中心。Chrome/Edge真实渲染测试检查全校区入镜、全屏尺寸、拖拽位移、放大、两模式、旋转、边缘拖动和四角在数据范围内。
- 地点87条：原75 + 南苑13栋真实OSM轮廓 + 3食堂 + 活动中心 + 友苑 + 师苑2栋 + 5个复合建筑地点。29项名称规范来自负责人指定校区图及师苑逐栋回复，原名保留为搜索别名。照片/地图图片没有作为正式底图或纹理。
- 真实高德查询及同区步行服务在本地底图上的受控集成通过。截图来自供应商实际结果，并非测试夹具；入口/当前通行未实地核验，跨区隧道仍关闭。

## 测试条件与限制

Chrome和Edge均使用本机安装浏览器引擎的Playwright独立测试配置，桌面1440×900、手机视口390×844；不是用户原浏览器配置，也不是真实手机/Safari。页面加载计时包含本地服务/引擎初始化，只是本机证据，不能承诺公网延迟或FPS。

`map-live.spec.ts` 使用真实本地MapLibre与数据，不注入地图SDK夹具。`map.spec.ts` 仅在线高德服务使用隔离夹具；`map-online-live.spec.ts` 显式 `CAMPUS_LIVE_SERVICES=1` 才运行真实服务，不提交个人Key。

最终测试与Workers生产预览结果在 `PROGRESS.md` 记录。截图和每项状态见 `screenshots/s1/browser-fix/README.md`。
