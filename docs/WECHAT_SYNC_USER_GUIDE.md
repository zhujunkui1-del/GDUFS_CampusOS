# 公众号文章同步使用说明

> 2026-10-28：来源不再固定78。当前80个本地账号已全部接入（78公众号、2服务号）；常驻同步按公开账号ID/biz自动发现新增账号，忽略.campusos-locks，清单无变化不重复注册。来源启用无需先核验，手动停运/删除仍优先；新号文章沿原流程自动发布。详[本轮验收](WECHAT_ACCOUNT_DISCOVERY_2026_10_28.md)。

当前操作说明已更新至 2026-10-22：请阅读 [共享文章库与启停说明](WECHAT_SHARED_LIBRARY.md)。当前目录为 `D:\WeChat MP Tools_v2.3.1\data\articles_full`，支持 WeRSS 与 MP Tools，只新增/更新云端；当前用户登录自启已配置。下文保留 2026-10-21 阶段说明，其旧路径、单采集器、自启和删除描述不作为现行操作指引。

## 先理解目前能做什么

当前流程是：**WeChat MP Tools 下载文章 → CampusOS 本机同步程序每分钟检查下载结果 → 网站自动发布。**

网站已接通本地下载结果，但还不能直接在网页上启动 MP Tools 的公众号历史下载。MP Tools 的登录、历史目录获取和定时下载仍在电脑上的 EXE 中进行。文章日期门禁已统一到“过时信息清理”，同时控制后续导入和已存旧文章的清理。

## 一、首次补齐一段时间的历史文章

1. 打开 `D:\WeChat MP Tools\WeChat MP Tools.exe`。
2. 进入 **公众号管理**，找到目标公众号，点击该账号的 **文章**。
3. 在 **时间范围** 填开始和结束日期。例如补 9 月后的历史：`2026-09-01` 至 `2026-10-21`，点击 **按时间下载**。该程序按本机日期解释范围；电脑时区应为北京时间。
4. 等待任务完成，在 **下载历史** 查看成功、失败数量。失败和只取得标题均不等于全文下载成功。
5. 其他账号也通过各自的日期任务补历史。目前没有 CampusOS 网页一键发起 78 号历史任务的功能，也没有证明 78 号历史已完整覆盖。

已安装单文件 HTML 修正版（v4）：手动下载和 RSS 的新成功下载都只保存 `reading.html`，通常位于：

```text
D:\WeChat MP Tools\data\articles_full\公众号名称\文章标题\reading.html
```

账号、原文链接、原发布时间和实际下载时间通过不执行代码的 meta 标签嵌入 HTML；图片和背景引用微信 CDN，排版样式仍在 HTML 中，不另存图片、JSON、PDF、Markdown。旧下载的多格式文件仍保留并继续兼容。

v5起文件夹按文章标题命名。同一原文链接重复下载覆盖同一份HTML；不同文章重名时追加短标识，Windows不允许的引号、斜杠等字符替换为下划线。已下载“广外青年”的两个哈希文件夹已更名，下载历史路径同步更新，正文未改动。

缺少原文发布时间时，HTML仍正常保存，日期标为未知；CampusOS会跳过这类文件。日期未知与下载失败是两件事，不能使用下载时间充当原文时间。

## 二、让下载结果自动进入 CampusOS

### 当前这台电脑

1. 双击 **`D:\WeChat MP Tools\启动 CampusOS 同步.cmd`**。已运行时会提示已运行，不会启动第二个同步进程。提示窗口可以关闭，后台同步继续。
2. 打开 [后台公众号采集](https://campusos-preview.zhujunkui1.workers.dev/admin/collector)，点击 **刷新**。查看加粗的 **最近在线**，正常情况下时间每分钟更新；“等待新内容”表示在等新的本地成功下载。
3. 如需纳入 9 月文章，在 **过时信息清理 → 文章日期门禁** 输入 `2026-09-01`，点击 **预览清理文章**。逐项核对数量、标题、原文发布时间、来源及原文链接后，点击红色 **确认门禁时间**；不执行时点 **取消**。规则为清理日期以前的文章，保留当天及以后，白名单保护项保留。当前门禁仍是 `2026-10-01`；本轮没有替你确认新的日期或删除文章。此门禁适用于全部公开信息源，包含官网文章，预览中会逐项列明来源；不会删除信息源登记。
4. 新文件完成后，通常下一轮约一分钟内开始导入；文件较多或网络较慢时整批完成会更久。刷新查看各账号文章数量，点击账号名称进入该来源的 **全部文章**。
5. 用户可以在 **校园雷达 / 校园知识** 中打开 **阅读全文**，文章仍保留 **查看原文**。

同步程序只接收已登记账号、具有原文发布时间和可阅读正文的成功导出。重复扫描相同文件不会重复发布；同一原文链接取得较新正文后替换当前阅读版。没有原文时间、日期早于起日、账号不匹配的文件会跳过。

### 关闭、重启电脑以后

- **只暂停向 CampusOS 同步：**双击 `D:\WeChat MP Tools\停止 CampusOS 同步.cmd`。它不停止 MP Tools 自己的下载任务。
- **恢复同步：**重新双击启动文件。续传记录会避免重复导入。
- **电脑重启后需要再次启动。**当前没有安装开机自启或系统服务。电脑关机、休眠时不能继续下载和上传。
- 仅同步已下载文件时可以关闭 MP Tools；需要它继续定时下载时，MP Tools 也必须保持运行。
- 启动文件引用当前项目位置；移动项目目录后需要重新运行 `services/wechat-collector/install-shortcuts.ps1` 生成入口。

## 三、以后如何自动获取新文章

以下按钮名称已按本机安装包的实际界面源码核对；本轮没有替你开启新的上游采集任务。

1. 在 MP Tools 的 **公众号管理** 找到账号，点击该账号的 **RSS** 按钮。
2. 开启 **自动订阅抓取**。
3. 在 **抓取时间间隔** 选择更新间隔；程序显示的是随机间隔范围，并不是某个固定整点。选择 `1440` 对应的范围是较低频的日常更新选项；仍以该弹窗显示的时间范围和 **下次预计** 为准。
4. 在 MP Tools **设置 → RSS 订阅时间段配置** 查看允许自动采集的开始、结束时间。不在这个时间段内时不会立即执行。
5. 通过该弹窗的 **订阅状态 / 上次抓取 / 下次预计** 和 **下载历史** 确认新文章确实下载成功。保持 MP Tools 与 CampusOS 同步程序运行，后续成功文件会继续自动发布到网站。

**无需复制 RSS Feed 地址到 CampusOS，也无需打开 MP Tools 的“上传历史文章”或配置它的第三方上传网关。**当前 CampusOS 使用本地文件同步；RSS 在这里负责让 MP Tools 产生新的下载文件。

本轮本地配置盘点：78 个账号已加入公众号管理，但 RSS 只有 **外环东路178号的猫** 一个启用项，配置值 **720 分钟**。因此目前不是“78 个账号均已定时更新”。新增账号以后，也需要先登记到 CampusOS 的公众号范围，并加入 MP Tools；已有 78 个范围内的账号不需要重复添加。

RSS 用来增量收取最新文章，不能代替第一次历史回补：当前调度器每次最多取 5 页、每页 10 条，并在遇到已有文章时停止，不保证把缺失的整段历史补齐。它也会跳过已有文章，不能当作逐篇旧文章更新、删除检查器。

## 四、凭据、勾选框分别是什么

| 原控件 | 作用 | 本轮处理 |
|---|---|---|
| 本地进程凭据 | 本机向 CampusOS 上传文章的身份校验，只允许写入指定公众号 | 已改为长期有效，直到管理员在“连接状态”撤销 |
| 每个公众号左侧勾选框 | 选择批量操作范围；原先不选就表示全部 | 删除，页面统一处理当前登记的公众号 |
| 启用采集与展示 | 批量改动采集策略，关闭后可能影响文章展示 | 删除；修改日期时保持各账号现有启用状态 |

“凭据”不是公众号的微信密码，也不是让你每天填写的东西；它已经保存在 `D:\WeChat MP Tools\data\CampusOS_collector\config.json`，不需要复制到文章或聊天中。当前连接已按负责人决定改为长期有效、可撤销，原 90 天期限不再适用。撤销连接只停止后续上传，已发布文章仍可阅读。后台继续校验来源范围和管理员状态。

MP Tools 的微信登录失效与 CampusOS 连接是两件事；把后者设为长期有效，不会让微信登录变为永久。按程序正常授权入口处理下载登录；不要将公众号登录信息填到 CampusOS 文章字段。

## 五、文章没有出现在网站时，按这个顺序看

| 现象 | 查看位置与处理 |
|---|---|
| 只有标题、下载失败，没有全文 | MP Tools 下载历史；先取得成功导出。网站不能把失败任务变成全文 |
| 下载成功，但最近在线时间很旧 | 双击启动同步；保持电脑运行，再刷新采集页 |
| 最近在线正常，但 9 月文章未导入 | 在过时信息清理查看门禁；纳入9月须预览并确认9月1日门禁 |
| 其他跳过或上传错误 | 查看 `D:\WeChat MP Tools\data\CampusOS_collector\last-sync.json` 与 `worker.stdout.log` / `worker.stderr.log`；只看错误码，不公开配置中的 token |
| RSS 一直没有新文章 | 检查该账号是否开启自动订阅、允许采集的时间段、MP Tools 是否运行、正常登录是否有效 |
| 原文被删除，但网站尚未下架 | 独立定时原文巡检尚未接通，不能声称已自动发现；访问失败也不能作为删除证据 |

目前真实已导入 **67 篇、3 个公众号**：广外就业 53、广外就业中心 7、外环东路178号的猫 7。其余账号已登记不等于已有文章全文。保留原有官网 52 篇；没有因本轮界面调整删除文章或改动官网。

图片由微信原图 CDN 加载，背景 CSS 与图片 URL 保存在网站 HTML 中；本地旧 `media` 不是网站的图片服务器。CDN 图片是否长期可用仍取决于原站，当前没有另建图片仓库。
