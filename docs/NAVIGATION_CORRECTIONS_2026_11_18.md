# 导航绕行、定位与白云山交互修正（2026-11-18）

负责人提供第四教学楼北侧选点、经西门去51栋的截图，要求校外引导不得斜穿教学楼；误差108米也必须保留坐标和导航能力；白云山规划前需显示与大学城一致的起/终标志，普通地图/专注导航应能右键旋转，手机继续适配。

## 实施

上一版外点—最近门采用直接虚线，没有避开楼体，是本次错误根因。现从已在仓库的固定OSM上下文提取道路和楼体，不重新下载、不改二维图形或主校内路网。外点投影到可连接源道路，经源节点图到最近已有校门，楼体阻挡的段及接入线排除，优先外围道路；保持虚线样式，不把引导加入校内已核验道路。距离按最终几何长度计算，选路的外围惩罚不计入距离。两端均在校外仍按上一轮授权直线虚线；此轮修正一端校内的接入。

该示例实际沿云溪五路（way687762421）向西、白云大道南地面路段（way443806029）向南，西门附近接入道路（way963009197），再进入校内路径。不会用不准步行的高架/机动车匝道替代道路；foot=no/private、已锁定、明确禁行段过滤。校区边界是粗粒度OSM范围，不拿它裁断贴边道路；外围选择参数按固定边界与校门邻域作用于实际源路段，不生成沿围墙的假道路。无法找到连接时不回退穿楼直线。

大学城移除误差>100隐藏位置/拒绝设置起点及>50阻断导航进度的旧客户端分支；合法坐标继续显示，面板显示误差值，允许规划和开始导航。白云山持续定位也先保留位置、误差与地图精度圈，不因大于100米拒绝；过期样本不推进实时进度、权限/无效数值/后台停watch保持。未修改AI共享位置的挑战鉴权、服务端精度或隐私校验。

白云山选点、文字选楼、定位起点和交换均同步原route-endpoint样式的起/终Marker；规划前就显示，关闭/重置/退出清理，异步Marker加载按修订号失效。右键拖拽和双指旋转恢复，maxPitch=0保持2D；专注导航也允许旋转，朝北/路线朝上按钮保留。
