# 两校区导航接入与手机体验验收（2026-11-18）

## 范围与实现

负责人要求修复白云山缩放/拖动卡顿、遮挡地图选点的通知、导航功能与大学城不一致，以及端点远离步道或位于校外不能规划的问题，并补充手机体验要求。

- 白云山直接复用 `FocusedNavigationView`，开始导航后收起搜索、账号/留言/访问量、规划面板、主导航与助手入口；方向、路程、剩余时间、到达时间、定位、朝向与退出控件共用。白云山保持2D。
- 手机地图选点时折叠步行面板，选后展开；无顶部选点横幅。显式“我的位置作起点”在面板内报告正在定位/没有权限/失败，导航中在底部卡内报告，不弹失败窗口。明确建筑端点不自动索取GPS。
- 规划线路按实际可见的搜索栏、规划面板、工具和底部主导航计算留白；面板尺寸及横竖屏变化重新适配。横屏专注导航信息卡位于左侧，路线使用右侧较大连续区域。
- 两校区：校内端点以虚线接入可连通步道路网，白云山接入最大真实连通分量的最近线段投影，不再使用100米硬拒绝。实线仅沿原固定OSM路网；不新增或伪造路段。
- 一端校外时，经现有校门目录中欧氏距离最近的门，以虚线接入步道；两端都在当前校区外则直接虚线相连。虚线是几何引导，不是现场核验、可通行或跨校区实线路径；不增加在线道路数据。大学城保留原校内穿行/隧道规则。
- 白云山隐藏标签从MapLibre移除、可见时恢复；按帧合并避让计算，变化时才改样式/偏移。没有改动GIS坐标、轮廓、模型文件、路网快照或供应商。

## 数据与定位边界

沿用 `baiyun-2026-11-18.2`、`baiyun-walking-2026-11-18.1` 和原大学城版本/负责人校门坐标。OSM遵循既有ODbL署名；没有下载新地图/照片/受限瓦片。端点/设备位置仅当前页面内存，退出/关闭/离页停止watch；没有上传或持久化轨迹。
