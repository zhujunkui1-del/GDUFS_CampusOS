# 2026-10-25 官网采集 D1 读写优化

负责人要求直接修改 SQL 和重复写入逻辑。本轮不新增官网入口查找，不改变公众号采集，不增加应用日采集配额；官网文章仍自动发布，管理员下架保持有效。

## 修改

- 跨 URL 去重先按标题、原文日期、发布机构筛选，再检查来源与正文哈希。去掉抓取历史 JOIN 和 DISTINCT；匹配规则不变。
- 来源证明绑定当前修订和 input_hash，用文档抓取覆盖索引查找；保留成功抓取、快照和 source_author 约束。
- 迁移 0042 添加去重索引、抓取覆盖索引及缺少的文档外键关联索引。列表页、无文档候选的 nullable 外键用部分索引，避免额外索引写入。
- 来源保持运行中，领取任务时只在状态或执行器改变后写一次。每页检查点、租约、fence、幂等命令和审计仍写入；来源总览在完成或出错时合并写一次。
- 下一次自动采集时间以本轮成功完成时间加当前统一间隔计算，避免长任务结束后立刻再次到期。
- 正文状态合并到文章 INSERT / UPDATE；出处 UPSERT 后不再重复 UPDATE 同一出处。
