# M3 报名与活动时间提取

在已完成 M1/M2 的输入输出上增加 `analyzeArticle`，先正文分段和报名锚点，再将邻近日期绑定到报名、活动或作品/材料/缴费等其他业务角色。支持多轮、显式活动标题、多阶段赛程；不使用系统日期补“即日起”。无时刻保留 day，无可信年份保留未知，有年份推断时逐字段记依据。取消/改期与按当前时间推导的状态不覆盖发布/撤回状态。

18项日期提取单元通过，连同分类与契约合计43项通过，typecheck及新增文件ESLint通过。包括报名/举办时间不混淆、作品截止独立、多个活动、跨年、额满即止、附件/图片未取文本、已过报名期仍保留报标记。

真实微信案例“金融学院第六届金融热点分析大赛参赛指南”：报名截止 `2026-10-25T20:00:00+08:00`，源句“报名截止时间\n2026年10月25日晚20:00前”；作品提交有独立证据，复赛和决赛保留独立赛程。未调用OCR或模型，也未下载图片。

初版1773篇离线语料中295篇发现肯定报名证据、125篇有可归一化报名截止；这两个数字是提取覆盖量，不是准确率。日期置信采用规则等级，不声称统计校准概率。尚无独立大样本报名人工准确率，低证据字段保留未知。本阶段无云端写入、模型调用0。
