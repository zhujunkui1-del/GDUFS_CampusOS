# M2 标题与正文统一分类器

`classifyArticleContent` 是无网络、无数据库、无模型调用的纯函数。先提取正文的规则条件、操作步骤、服务目录、阶段窗口、临时变化和事件报道等证据，再判定主用途与业务分类。标题仅是候选特征；来源身份不投票。编号标题不再直接等价于办事流程，发布时间不等于政策有效期。

混合内容只产生一个主栏目，辅助用途单独保存。无正文或用途证据不足输出 unknown，两个业务分类为空；不会默认校园公告。现阶段 unknown 保留，后续可复用已授权模型辅助；本轮模型调用为0。

25项契约/分类单元通过，typecheck、目标文件ESLint、生产构建通过。离线1773篇的初版预测为雷达807、知识40、待分类926；旧雷达转知识40、旧知识转雷达20、旧知识待分类18。此处是预测，不是已上线数量。23篇针对性真实回归样本符合预期23篇，存在调参重用，不能据此报告独立总体准确率。

真实案例：

- 2027届电子就业协议操作指南（微信）→知识/升学就业，正文含连续操作流程，年份是适用届别。
- 金融热点分析大赛参赛指南（微信）→雷达/竞赛，正文含当届报名截止、复赛和决赛。
- 2027年推免硕士研究生考核实施细则（官网）→雷达/升学就业，正文为当前笔试面试时间地点表。
- 北校区学生生活指南（官网）→知识/校园生活，正文含服务目录与联系方式，不生成大学城地图坐标。
- 原知识栏目学习空间预约通知（官网，正文不可用）→待分类，保留原文章和可公开元数据，不制造正文证据。

详细预测在忽略目录 `test-results/article-analysis`，可运行 `node scripts/evaluate-article-analysis.mjs` 复现。当前尚未改写线上分类。
