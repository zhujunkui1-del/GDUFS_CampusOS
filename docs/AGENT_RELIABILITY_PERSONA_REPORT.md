## P3：可靠性行为契约

- 明确内容查询使用有界的服务端只读计划，内部RAG后按来源性质和实际缺口补外部搜索。沿用既有权限、Schema、取消/超时、12次工具/6轮上限。轨迹origin=server_plan，与模型自主选择的origin=model分开；不制造模型function call日志。地图保留现有动态工具调用与浏览器回执。
- 时间由服务端上海时区解释：这一周为含当天的7日，本周为周一至周日，新闻截至当天。publication/event/registration分开约束；追问中新时间覆盖旧时间。文章日期不能充当活动/报名日期。公众号、官网现有公开权限、人工下架、墓碑和版本复核保留。
- 小红书events请求可真实调用原生后端；近期查询使用已核实SDK的time_descending。返回日期未知或在范围外时不作为该范围证据。只看小红书不混入普通网页；官方政策/身份/时限仍走官方渠道。
- 连续指代追问保留最近具体主题，略过纯反馈和人格控制；最多回看4个用户轮次，最终检索query仍限制300字符。历史模型文字不作为事实证据。不是无限期实体记忆。
- 附属学校来源未明确涉及大学本部时，不自动当作大学校园事实；来源名称不能代替事件主体。
- 无可用正文或所需学生体验证据时，证据门禁直接说明缺口，不调用表达模型猜菜、编政策或伪称已搜索。失败与无结果不同，不能据此认定信息不存在。部分正文存在时仍由模型综合，尚无覆盖所有自然语言断言的完备验证器。
- 非法引用编号、关闭/严肃时未收敛及虚构亲身经历有表达冲突检查；拒绝不合格回复，不改写工具数据。纯问候、确认和情绪反馈无需模型与检索，仍保留会话鉴权、请求去重及运行锁。
