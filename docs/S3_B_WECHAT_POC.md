# S3-B｜微信候选工具独立研究与受限 PoC

核查日期：2026-10-17。范围：本地独立实验，不是 CampusOS 微信采集功能验收。**三工具均未接入 Worker、D1 或正式 Connector，真实文章抓取 0 篇、公开发布 0 篇。** 官网流水线和管理员人工提交元数据不依赖这些工具。

## 1. 先查策略，明确停止点

实际读取 [搜狗微信 robots](https://weixin.sogou.com/robots.txt) 与 [微信公众平台 robots](https://mp.weixin.qq.com/robots.txt)，两次均 HTTP 200。搜狗默认 `User-agent: *` 禁止全部路径；微信默认禁止全部，仅首页和少数帮助、登录等路径例外，文章 `/s/...` 不在允许路径内。本轮按项目要求停止搜索和文章请求，没有更换身份、代理、Cookie、账号或接口继续探测。这是采集策略阻塞，不能据此断言目标公众号没有文章。

只保存策略 URL、响应码、字节数、SHA-256、时间和允许判断，未保存响应 Cookie、正文或完整请求头。两次策略请求分别约 260 ms / 238 ms；属于壁钟时间，不能当 Workers CPU。见 [local-poc.json](verification/s3-b/wechat/local-poc.json)。robots 是本轮技术门禁证据，不是内容版权或全文转载授权。

## 4. 实际执行的离线检查

本机已有 Python 3.12、requests、lxml、BeautifulSoup；未安装 MCP、httpx 或完整 WeRSS 运行依赖，未启动服务器或 Docker。以 AST 从只读源码选取纯函数到内存，合成输入与 Mock 网络响应完全隔离，未导入会自动初始化数据库/任务的应用模块。10 项检查按预期通过，其中 3 项是**成功复现缺陷/局限**，不是功能成功：

| 工具              | 合成检查                                                                    | 结果                                                 |
| ----------------- | --------------------------------------------------------------------------- | ---------------------------------------------------- |
| Weixin Search MCP | 反爬页识别；strict 模式拒绝                                                 | 2 项符合预期                                         |
| Weixin Search MCP | 默认模式吞反爬为空列表；发布时间仍是 JS 文本                                | 2 项局限复现，生产适配必须改为可区分错误和带时区日期 |
| BlogDistiller     | 空元数据不补造；时间戳转 UTC+8；重复标题规范化                              | 3 项符合预期，仅证明这些纯函数行为                   |
| WeRSS             | 拒绝验证壳；旧式 js_content 正文剔除 script；JS-only 新壳抛 invalid_content | 2 项符合预期 + 1 项局限复现                          |

原目录 7 个受检文件执行前后 SHA 一致；另有 10 个与当前上游的比对。没有使用上游源码中的静态 Cookie，也没有在日志或证据中输出该值。结果与每项毫秒耗时见 [local-poc.json](verification/s3-b/wechat/local-poc.json)。复现脚本见 [wechat-local-poc.py](../tests/integration/wechat-local-poc.py)；从仓库根目录执行，需要原只读资料目录和上述本机库。脚本只请求两份 robots，随后运行离线夹具；不请求文章。离线合成内容不进入 D1、审核队列或公开页面。

## 5. 适配边界与降级方案

当前不正式集成三个引擎。将来只有平台/账号明确授权、robots/条款重新通过、来源认证和工具许可完成后，才评估本地独立运行；Workers 只接收经管理员鉴权的受限导入包，不在用户请求链路启动 Python/Docker。

拟用独立导入格式 `wechat-metadata-import/v1`（设计，尚非新增 API）：`sourceId, canonicalUrl, originalUrl, title, publisherRaw, publishedAt?, fetchedAt?, sourceUpdatedAt?, evidenceUrl, toolName, toolVersion, observedAt, rightsScope`。正文可选，缺少许可默认只收元数据、原文链接和管理员自写短摘要；不带 Cookie、token、请求头、微信私人消息或图片。所有记录回既有来源/文章版本/审核任务，不另建权限库、不自动批准或公开。

URL、发布者和日期须逐项验证；短链 token 不自行推造。已知 URL 的规范化保留能标识文章的必要参数，只移除已确认跟踪项；不把栏目页或公众号名称当文章。抓取失败与真实无结果分开，风控/登录/许可失败暂停，禁止失败重试风暴。新内容 hash 改变才重新处理，仍须当前来源权限和内容版本门禁；不得跨来源继承版权或核验结论。

可独立推进的路线：合规官网文章、负责人提供的合法公开原文链接、人工填写标题/元数据/自有摘要，经 Console 审核后使用。未经许可不复制整篇微信文章；公众号工具阻塞不阻塞官网采集与 S3-A 审核基础。

## 6. 尚未通过的门槛

- 三账号微信认证主体与近期文章人工抽样；不能将目录候选改为 verified。
- 三工具真实发现、真链、正文、发布时间、发布者、重复及增量指标；本轮均未测。
- 当前 robots 不允许自动搜索/文章采集，继续自动化需合法授权路径，不能以换工具或换 UA 绕过。
- BlogDistiller 平台集成许可；Weixin Search MIT 声明的版权/分发文件；三工具源码安全与持续维护评估。
- 若将来启用授权本地执行器，还需超时/进程隔离、容量、持久检查点、单站频率、依赖固定及凭据撤销。当前不增付费资源、不借用已过期模型预算、不进入 S3-C。
