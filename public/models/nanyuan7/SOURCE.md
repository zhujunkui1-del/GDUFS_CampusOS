# 南苑7栋模型来源

OSM footprint: https://www.openstreetmap.org/way/312536955 — © OpenStreetMap contributors, ODbL-1.0.

7 floors / approximately 21m: project owner, 2026-10-14; not a surveyed height.

2.5D retains the V1 volume. Active 3D: nanyuan7-v2-2026-10-14, approved by the project owner on 2026-10-15. Both desktop and mobile use the same lightweight asset (80384 bytes / 4748 triangles / 7 model draws / 5 materials / zero textures).

Original procedural geometry/materials. Supplied dormitory photos informed the simplified cream frames, terracotta walls and open galleries; no photo pixels, textures or supplier meshes are included. Exact facade orientation, bays, stair cores, canopy and courtyard are visual approximations. Source footprint, place coordinates and navigation data are unchanged.

Editable source: scripts/build-nanyuan7-v2.mjs and docs/model-previews/nanyuan7-v2/design.json. Approved promotion: scripts/publish-nanyuan7-v2.mjs. Active hash/geometry: src/features/campus-map/data/nanyuan7-model.json. V1 GLBs remain available as historical assets; their original manifest is docs/model-previews/nanyuan7-v1/manifest.json.
