# 10｜Campus Moments 校园动态与空间社交（P2）

## 1. 产品定位

**独立第九模块，P2 后续功能，不阻塞地图/Agent/RAG/账号初赛核心产品。** 目标是让学生围绕真实广外大学城公共地点分享趣事、临时情况、求助与交流，地图上展示内容而非追踪个人。

功能候选：地点动态（图文/短视频）、地点聊天室、附近求助、限时消息、校园广场、附近的人（自愿位置展示）。用户可以通过校园地图图层或独立动态页面进入。

## 2. 用户同意的“双开关”

| 开关 | 所在界面 | 默认 | 意义 |
|---|---|---|---|
| `viewNearbyPeople` | 地图图层菜单 | **关闭** | 我想查看附近**已自愿公开**的用户 |
| `shareMyLocation` | 账号隐私设置 | **关闭** | 我允许别人以受控方式看到我的模糊位置 |

两开关必须**完全独立**；开启查看别人不意味着自己公开。开启分享需登录、浏览器位置授权、主动确认展示范围与时长；关闭后立即停止公开位置服务。浏览器定位授权本身并不等于授权向其他用户展示。

## 3. 位置保护机制

- 不公开精确实时 GPS 坐标、宿舍房间号、完整历史位置轨迹。
- 优先以**公开建筑/校园区域**为展示粒度，也可显示合规的模糊化位置范围；不应通过反复观察缩放或更新时间推断个人精确行动。
- 位置共享支持选择 30 分钟、2 小时或本次会话期间，到期自动关闭；支持立刻撤回。
- 用户可随时隐身、屏蔽、举报、拉黑；位置显示频率限流，可设置最小展示人数门槛，避免通过只有一人的地区推断其身份。
- 未成年人身份、位置隐私和其他适用法律要求须上线前专门评估。

## 4. 地点动态（与附近的人分开）

发布文字、图片、视频和标签；用户可选择**绑定已确认的公共 `placeId`**（如图书馆），也可发布到校园广场但不附精确地址。别人点开地点查看动态，并不意味着可以查看作者真实位置。

动态可见期：1h、6h、24h、长期；到期不再公开显示。需要清楚说明到期后的缓存、合法审计留存规则，不承诺瞬间删除所有记录。

## 5. 地点聊天室与求助

- 依据建筑/公共区域建立可进入的讨论板块；不是每条道路永久建立聊天室。
- 求助帖有类型、地点、有效期、`open/resolved/expired` 状态；支持留言与分享；紧急情境引导官方求助渠道，不替代应急服务。
- 对校园实时事故、停电、封路等用户内容增加**未经官方证实**的区分，不由 Agent 当成已确认校园通知。

## 6. 审核和运营

- 登录后才允许发布；游客浏览权限可由产品配置。
- 文字/图片/视频审核，投诉举报、删除、用户拉黑、限流、防刷屏/广告、防骚扰、隐私举报、伪冒学校官方内容处理。
- 媒体大小、格式、转码/鉴黄/违规内容处理与 CDN 成本上线前需要预算和技术审批。
- 动态与官方活动、知识搜索在 UI 中使用明显不同的信息来源标记。
- 社交帖子不可未经审核直接流入官方知识库，也不应自动成为 Agent 事实依据。

## 7. 未来数据库

`social_posts(id,author_id,place_id?,text,visibility,expires_at,status,created_at)`；
`social_media(post_id,asset_id,type,moderation_status)`；
`social_comments(id,post_id,author_id,content,status)`；
`social_reports(id,reporter_id,target,reason,status)`；
`social_blocks(user_id,blocked_user_id)`；
`location_share_consents(user_id,scope,expires_at,revoked_at)`；
`nearby_presence(user_id,approx_zone_id,expires_at)`；
`social_moderation_logs`。

精确原始位置不应长期存储在附近展示表中。位置查询 API 必须有身份验证、速率限制、展示粒度和可见范围校验。

## 8. 未来页面与图层

- `Campus Moments` 可通过地图 `MomentsLayer`（默认关闭/用户开启）浏览聚合数量，缩小时合并标记。
- 地点详情中新增“校园动态”标签；抽屉显示通过审核的内容列表。
- “附近的人”使用专门开关图层，开启前说明可能看到的只是模糊化区域，不显示跟踪轨迹。
- 手机端动态页面可从“我的/更多”或 P2 迭代后的导航入口进入，初赛不强塞底部第六项。

## 9. 发布前的额外验收

- 两开关默认关闭、互不影响；撤销分享立即停止新位置返回。
- 发布图书馆动态并不让其他人看到作者精确位置。
- 未登录不能发布、刷帖/恶意上传被拦截。
- 违规帖子能被审核撤回；用户举报有处理流程。
- 点位聚合无法透出用户单独行踪；前端地图刷新不泄露原始 GPS。
