# 06｜前端 UI/UX 与跨页面交互设计

## 1. 前端定位

**仅开发响应式 Web**（桌面+手机浏览器），不做原生 App。采取广外蓝白 + Apple 式克制、柔和圆角、信息层次清楚、地图内容优先的视觉语言。桌面：左导航、中央全屏校园地图、右侧可关闭 Agent；手机：全屏地图、顶部搜索、底部五项导航及可拖动的 AI 抽屉。

## 2. 六大功能页面

| 路由建议 | 业务页面 | 重点操作 |
|---|---|---|
| `/map` | 校园地图（默认首页） | 建筑/设施、2D/2.5D、路线/AI 联动 |
| `/radar` | 校园雷达 | 活动讲座竞赛、报名截止、信息溯源/地图定位 |
| `/schedule` | 个人日程 | 课表、任务、时间冲突、路线规划 |
| `/knowledge` | 校园知识 | 官方政策、学院通知、非官方经验、办事指南 |
| `/favorites` | 我的收藏 | 保存地点、活动、通知和常用入口 |
| `/account` | 我的账号 | 登录、手机号、安全、学校服务连接、AI 记忆、AI 模型设置 |

AI 助手是**所有页面共用的全局组件**，不需要强制成为第七个一级页面；可提供 `/assistant` 专注聊天模式作为辅助入口，但不能产生独立割裂的 Agent 身份和会话。

## 3. 桌面端布局

- 左侧导航：默认 64～72px 图标模式，可展开约 180～220px；记录展开偏好。
- 中间地图：占据剩余主空间；当前视角、可见图层、选中地点、路线持续存在。
- 右侧 AI：默认可收起，展开约 360～420px，也可按宽度调整；非地图页面仍可打开。
- 按负责人 2026-10-12 的修订：删除常驻顶层栏。品牌与校区信息整合到搜索浮层，账号/游客信息放入导航；保留地图完整视野。
- 地图浮层：地图区切换、图层、2D/2.5D、缩放、定位、地点详情、路线时间线。
- 独立知识/雷达/日程页面共享统一导航与全局 AI；不要让右侧浮层挡住主操作。

## 4. 手机端布局

- 单一 Web 响应式实现，手机不强制登录。取消常驻顶栏；品牌/校区随搜索浮层呈现，账号在工具入口及“我的”管理。
- 全屏地图、顶部搜索、适合单手操作的地图工具。
- AI 通过右下角全局入口打开**底部抽屉**：`collapsed`（地图为主）/`half`（上方保留地图）/`full`（长对话阅读）。抽屉处理系统键盘和安全区域。
- 底部五项导航为局部半透明浮动胶囊：**地图、雷达、知识、日程、我的**；`我的` 内管理收藏和账号。
- 触控最小目标约 44px；不要求 Hover 交互，移动端地图精度和清晰度优先。
- PWA 可后期评估，但不影响普通浏览器使用。

## 5. 全局 Agent 三入口

1. 每个页面可见的**问 AI** 图标/按钮。
2. 顶部统一搜索支持传统地点搜索，也允许用户提交自然语言复杂需求（要清楚区分两类操作）。
3. 建筑/活动/知识/个人任务卡中的“问 AI”，自动携带当前 `placeId/eventId/documentId/taskId`。

三入口全部指向统一的 `conversationId` 和 Agent Orchestrator。

### 对话消息类型

文本回答、引用来源、地点卡片、活动卡片、路线卡片、日程操作确认卡、工具实际执行进度、系统错误与重试。地图行动卡点击后在真实地图中定位；不能只是装饰卡片或预先写好的回答。

## 6. 跨页面跳转矩阵

| 来源 | 动作 | 结果 |
|---|---|---|
| 雷达 | 查看活动地点 | `/map?place=<id>`，定位并打开地点 |
| 雷达 | 加入日程 | 登录校验 → 确认 → 创建本人日程项 |
| 地图 | 查看建筑相关通知 | `/knowledge?place=<id>`，展示有关资料 |
| 地图 | 问 AI | 保留地图选中地点传给会话 |
| 知识 | 查看办理地点 | 地图定位经核验的 `placeId` |
| 知识 | 打开原文 | 外部官网/小红书原链接（区分官方/非官方） |
| 日程 | 查看课程地点 | 地图定位；无地点匹配则提供人工选择 |
| 收藏 | 导航到地点 | 地图起终点规划 |
| AI | 展示路线 | 下发 `SHOW_ROUTE`，地图画线和时间线 |

保持页面切换后的地图当前视角、路线和 AI 对话；路由参数中的 ID 仍需校验。

## 7. 地点/路线/活动统一卡片

**地点卡片**：名称、区域、用途、设施信息、图片/全景（如果有许可）、真实来源、`去这里/收藏/问 AI`，可选相关通知。

**路线卡片**：起点、终点、多站清单、距离/预计时间（实际算法）、步骤、调整顺序、冲突与来源，选中后地图同步高亮。

**活动卡片**：主办、开始/截止、校园归属、地点绑定、原文入口、`查看地图/加入日程/问 AI`；无法核验地点时没有可点击的虚假地图定位。

**知识卡片**：标题、官网/非官方标识、发布时间、适用范围、原文链接以及 AI 追问；小红书信息仅为参考性质。

## 8. 登录、游客与学校绑定

- 游客可直接进入 `/map`，不弹出遮挡式强制登录。
- 游客点击收藏、保存会话、保存个人日程等私有写入时，才显示登录引导。
- 账号中心提供个人信息、手机号绑定找回、安全设置、学校服务连接（需真实校方授权）、AI 记忆/历史、AI 模型设置及隐私与偏好。
- 尚无学校正式授权能力时显示诚实的未接入状态或隐藏绑定操作，不放虚假成功结果。
- 用户登出时清理受保护缓存及本地敏感上下文，公共地图继续可用。

## 9. 页面状态

- 前端 UI：使用全局状态管理（例如 Zustand）保存地图模式、面板开合、选中实体；避免重复请求。
- 业务数据：通过 API query cache 管理活动、地点、日程与收藏；需服务端权限校验。
- 会话：服务端存储 `conversationId`、消息和真实工具执行状态。
- 持久化偏好：非敏感选项可保存在本地/账号设置；不默认收集持续精确 GPS 轨迹。
- 错误处理：加载失败重试、无搜索结果、地图 SDK 配额耗尽、模型超时/不可用、短信失败、权限失效，都要提供可用反馈。

## 10. 视觉系统与附件

详见 `11_VISUAL_SYSTEM.md`。两张生成视觉图位于 `assets/ui/`，用于表现蓝白配色、半透明浮层、地图与 AI 布局；其中照片、建筑及活动数据**不等于经过核验的真实广外地图或公告**。Codex 不得直接照着视觉图里的路线、活动内容写入数据库。

## 11. 无障碍、国际化与性能

- 键盘可操作主要导航、按钮、表单；支持屏幕阅读器标签、颜色对比、减少动画偏好。
- 校园多语言导览是可能扩展项；工程可使用 i18n 结构，但第一版中文内容必须准确。
- 半透明/blur 优先作用于小块浮层，不对地图做全屏高开销背景模糊。
- 长列表虚拟化、图层懒加载、移动端 2D 性能回退。

## 12. 前端验收

1. 无登录可搜索地点并导航。
2. 电脑侧栏、AI 面板可展开/收起且不会压坏地图。
3. 手机抽屉三态可用，不覆盖输入框或底部导航。
4. 雷达→地图→AI→日程→地图完整走通且正确保存状态。
5. 真实来源链接可打开；非官方标注清楚。
6. 登录后收藏/日程跨页面同步、登出后私人数据不泄露。
7. 默认2D；侧边一个按钮直接循环2D→2.5D→3D→2D，文字为#1d1d1f，浏览和导航共用，不打开选项框。切换不丢失线路，进入导航时不让建筑挡住路线。

## 13. 个人中心 → AI 模型设置

按 `12_MODEL_API_SETTINGS.md` 实现账号内子页面，不添加一级导航或常驻顶栏。页面提供默认 DeepSeek/自定义 API 使用方式、供应商/模型/条件 Base URL、遮蔽 Key 输入、真实测试结果、保存/启停/切换/删除及当前模型状态。

游客可测试并临时使用，只有登录后可持久保存多份配置；已保存密钥只有“已保存/替换”操作，不提供明文显示。采用现有蓝白、系统字体、大圆角实白卡片和局部玻璃组件，桌面主区与手机单列均可操作。自定义故障保留当前会话，错误旁提供重测/切换入口；切换平台须用户明确选择。安全、字段、键盘/安全区和两端验收以第 12 份文档为准。

## 14. 地图导航修订（2026-10-13）

负责人要求移除分区快捷栏，不增加新的一级导航。地图工具提供定位；步行面板支持起终点地点建议、道路/标记选点、我的位置作起点、交换和确认规划。路线先显示真实道路结果，开始步行导航才请求设备定位；拒绝/低精度/校外/失去信号时明确提示，保留路线。结束、关闭、离开地图或后台停止追踪。地点入口未核验时说明终点为附近道路，不能宣称精准到门。

## 15. 手机专注导航与镜头（2026-10-14）

地图点选起终点不自动聚焦，文字选择地点以浮层无遮挡区域平滑聚焦；路线拟合让整条路径避开步行面板。镜头约220ms过渡、可打断，减少动态时直接切换。开始步行后隐藏搜索/主导航/图层/详情/AI，保留方向与当前段路程、总距/剩余时间/估计到达及侧边定位/退出/朝北-路线朝上/视角控件；3D未就绪禁用。定位失败保留此界面与真实路线，不推进虚假位置；退出恢复规划并清除起终点/路线。定位悬浮通知可关闭并约6秒自动消失，错误详情留在相关状态。AI窗口隐藏不清会话，键盘Esc可退出。

## 16. 简洁与导航退出（2026-10-14）

执行AGENTS第15条：地图操作界面去掉解释性小字，只保留操作、业务数据与简短可行动的状态；必要版权署名保留，地点原文使用正常字号的“查看来源”。路线规划成功后显示距离/时间、开始导航和重置；步骤按需展开。退出导航清除地图的路径与起终点。镜头实际600ms由快到慢，CSS时间单位按s/ms换算，以浏览器中间帧验收。校门坐标下一对话讨论。
