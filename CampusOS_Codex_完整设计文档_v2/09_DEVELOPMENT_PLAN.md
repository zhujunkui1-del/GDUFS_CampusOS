## 1. 开发基本原则

最终交付应为**可实际访问和使用的正式响应式 Web 应用**，而不是仅用于截图的静态页面。优先让大学城地图、地点查询、Agent 工具执行、RAG 引用这条核心链路真实可用，之后扩展用户日程、地图视效与其他能力。

开发内容区分：`must`（P0）、`should`（P1）、`future`（P2）。P2 社交和学校教务数据授权接口不得阻塞 P0。

## 2. 前置依赖清单（由负责人审批/提供）

- 高德地图开放平台 JS API 凭据及域名绑定；必要时测试百度 API 并比较大学城教学/生活区建筑覆盖。
- 可合法用于自有地点库的广外大学城建筑、体育设施、宿舍楼栋、校园路网与南校隧道入口数据；用户已经提供两张研究图，但不等同许可确认。
- 平台默认 DeepSeek 的实际模型 ID、端点、tool calling/JSON 能力、额度与计费预算；负责人已指定本地 `anykey.md` 为凭据交付位置，尚未读取/验证，实施时安全配置到 Secret。Embedding 模型及维度独立核验。
- 模型设置所需 Cloudflare 加密/测试凭证 Secret、HTTPS 预览/正式环境、审核供应商端点与限流/隐私保留策略；持久配置依赖 S4 真实账号。完整资源与安全要求见 `12_MODEL_API_SETTINGS.md`。
- Cloudflare 账户、域名、数据库/对象存储/向量组件配置。
- 手机短信服务供应商、模板与预算（若登录 P0 正式启用）。
- 官网来源白名单及采集规则；授权群聊导入文件、社交链接/素材须审核。
- 学校统一身份对接的正式 API/协议（未知、非当前 P0 前提）。

`docs/BLOCKERS.md` 逐项记录缺失授权或真实数据；**无权限时返回真实不可用状态，不得造假**。

## 3. 里程碑任务安排

### S0. 工程基线与环境（P0）

- 初始化 Next.js + TypeScript、Lint/formatter、单测、E2E、Cloudflare Workers 部署适配、路由结构和 `.env.example`。
- 定义数据模型、数据库迁移、日志/错误码、权限拦截、部署与回滚。
- 生成 `AGENTS.md`, `docs/DECISIONS.md`,`docs/PROGRESS.md`,`docs/BLOCKERS.md`,`docs/DATA_SOURCES.md`。
- 验收：空白但可运行的正式 UI Shell，在本地/预览环境启动，类型检查和构建成功。

### S1. 大学城真实地图闭环（P0）

- 集成高德 SDK、`MapAdapter`、大地图 UI、教学区/生活区视角、2D/2.5D 切换。
- 创建已有证据支持的 `campus_places`, `place_entrances`, `path_nodes/path_edges`；验证体育设施、楼栋与南校隧道。
- 实现地图地点标注随缩放出现、建筑详情、搜索、实际步行路线（只对已验证路段标记成功）。
- 验收：在一个页面呈现两区、选中真实地点、获取可验证路线；未知路径正确提示不足。

### S2. Agent + 多 Skill + MapAction（P0）

- 工具注册器、JSON Schema、权限、错误处理、执行循环、流式 UI。
- 首批真实 Skill：`search_places`,`get_place_details`,`plan_route`,`control_map`，按条件增加 `search_campus_knowledge`。
- 按 `12_MODEL_API_SETTINGS.md` 集成默认 DeepSeek、ProviderRegistry、服务端生成/工具/JSON 连接测试、错误分类与 Run 模型快照。建立游客临时 API 设置与 HTTPS 服务端调用，匿名限流/短期凭证/过期清理；自定义失败不自动消耗平台额度。
- 验收：用户自然语言询问地点，Agent 实际调用工具，地图自动定位；非真实地点不展示成功。
- 模型子任务验收：默认与临时自定义选择真实生效；工具不兼容时阻止 Agent 执行；游客无凭据持久化，HTTPS/端点策略及失败无回退通过。当前 HTTP 预览不用于真实 Key 测试。

### S3. 知识引擎与 CampusRadar（P0）

- 第一个正式官网 Connector、增量采集、文档元数据、向量/关键词索引、回答引用。
- 事件抽取、时间/地点校验与审核，CampusRadar 列表、原文跳转；只在大学城真实地点发布地图事件。
- RAG Embedding/公共后台模型独立配置，验证用户更换对话模型不改变索引、证据引用、数据权限或活动核验流程。
- 验收：至少一批经核实官方文档与活动可检索；旧日期和不明地点没有错误标注。

### S4. CampusOS 账号与手机登录（P0）

- 短信验证码服务、注册/登录/找回、游客模式、本人数据 API、权限测试。
- 账号模型设置子任务：兼容迁移新增模型配置/选择表，AES-256-GCM/Secret 版本管理，本人多配置列表、测试、启停/切换、Key 替换与级联删除；UI 保持账号内入口。只有真实鉴权与安全测试通过才启用持久保存。
- 验收：游客完整公共操作无阻碍；登录后独立账号数据与会话可以跨页面查看；登出后清理私人信息。
- 模型持久验收：跨用户读取/调用/修改/删除全部拒绝，数据库无明文 Key，已保存 Key 不回传，匿名保存拒绝，切换/删除不重复工具写入。

### S5. 个性化与多站任务（P1）

- 多站行程算法、可编辑时间线、用户课表导入/核对、任务/收藏云同步、长期偏好管理。
- 验收：修改多站顺序自动重新计算，冲突时间能提示；本人日程由确认后的 Skill 真实保存。

### S6. 视觉精修、实景与持续运营（P1）

- 蓝白 Apple 风格统一视觉、路网与体育标注完善、建筑实景合规接入、知识审核 Console、手机端性能优化、无障碍。
- 验收：真实授权素材展示；两端 UI 验收；文档链接不失效或能够报告失效。
- 模型设置回归：桌面/手机表单、键盘/安全区与长名称；模型切换和故障恢复覆盖地图、RAG、原 16 Skill 合约及业务幂等，P2 未授权接口继续正确拒绝。

### S7. 外部系统和空间社交（P2，独立里程碑）

- 在取得校方授权后接入学校 SSO/个人课表等；Campus Moments 动态/地点聊天室/限时消息/附近的人功能。
- 未有许可或审核资源不得进入生产，不需要为比赛时间牺牲 P0 可靠性。

## 4. 并行与依赖关系

关键路径：地图服务/地点数据库 → 路线 Skill → Agent MapAction → UI 联动；官网 Connector → RAG → Agent 引用 → CampusRadar 活动；认证 → 个人业务表 → 日程/记忆。

模型路径：平台 DeepSeek/受控供应商 → 真实能力测试 → Agent 模型选择；匿名会话/HTTPS/端点策略 → 游客临时 API；真实账号/Cloudflare Secret → 加密模型配置 → 本人选择。新增任务按 S2/S4 分批完成，不越过 S1 真实地图优先顺序，不提前接入 S7。

可以并行做地图 UI 外壳和 RAG 数据框架，但不能让视觉截图数据污染正式地点 DB。不要把一个大组件塞下所有地图与 Agent 行为。

## 5. 版本和项目控制

- Git 分支、提交信息与变更记录清晰，每个阶段先提交可构建版本。
- 环境：local / preview / production 分离。测试私有信息不得进 Git。
- 使用开关管理未完全准备好但不影响其他功能的模块，不得在正式站显示可点击却无效的按钮。
- 重大改动（换地图底图、收费服务、外部登录、上传第三方地图图片、扩大校区范围）必须负责人审批。

## 6. 技术测试矩阵

| 类别 | 最小测试 |
|---|---|
| 编译质量 | TypeScript typecheck、Lint、生产构建 |
| Agent | 真实 Skill 调用、歧义处理、失败恢复、预算/超时、提示注入防护 |
| 地图 | 2D/2.5D、完整两区、地下隧道、建筑搜索、路线坐标、移动端触控 |
| RAG | 官方来源引用、发布时间区分、非官方参考、撤回/过期、事件地点核验 |
| 账号 | OTP 限流、找回、登出、越权访问、游客降级 |
| 个人功能 | 课表导入核对、时间冲突、任务写入确认、收藏本人隔离 |
| UI | 跨页面状态保留、AI 面板收起/展开、空状态/错误态 |
| 依赖 | 地图 SDK Key 失效、模型服务失败、官网抓取不可用、短信配额不足 |
| 模型设置 | `12_MODEL_API_SETTINGS.md` T01–T18：默认/自定义、游客临时、加密/隔离/删除、真实能力测试、端点安全、无自动回退、幂等与两端 UI |
| 资源合规 | 未批准图片/地图/全景绝不进入公开资源库 |

至少准备三条可复现端到端真实任务：① 生活区→教学区经过核验路线；② 官网问题有出处且活动关联有效地图地点；③ 用户登录、存日程、Agent 检查任务时间。

新增模型设置必须通过负责人列出的 13 项验收及游客临时/安全补充项。常规测试使用 Mock Provider，受控真实集成测试通过独立 Secret 配置并限制调用预算；不得提交个人 Key。类型检查、Lint、单元测试、关键 E2E、生产构建和 Workers 预览请求都需留下证据。**本次追加规范没有执行这些开发/测试任务。**
