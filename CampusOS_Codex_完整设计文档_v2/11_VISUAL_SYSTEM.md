# 11｜视觉设计系统：广外蓝白 × Apple 式地图工作台

## 1. 方向

已确定：**B 方案（精致 2.5D 数字校园）融合 A 方案（简洁易读的地图标注）**。主视觉采用广外校园蓝白色，借鉴 Apple 界面的克制排版、圆角、柔和层次、半透明浮层和轻快动效，但不直接复制其具体专有图标或界面资产。

2026-10-12 负责人修订：采用 Apple-inspired UI + 局部 Liquid Glass + Minimalism。取消常驻顶层栏，使用局部半透明导航/搜索，内容面板保持实白；以常规/中等字重、克制的蓝色强调、柔和阴影与大圆角建立层次。具体实现与检查见 `../docs/UI_REVIEW.md`。

UI 视觉和校园地图地理信息分层：蓝白色负责品牌/控件；地图本身仍应保留合理的道路、绿地、水体、建筑和场馆色。

## 3. UI 组件

- 导航：浅白背景和显眼的选中蓝条；图标以统一 Lucide 线性风格。
- AI 面板：约 400px，轻微毛玻璃，消息卡和任务卡区分；有清楚的收起按钮与历史入口。
- 地点卡：大标题、区域、可核实信息、图/视频入口、`去这里` 蓝色主要操作。
- 路线卡：路线距离/时长、停靠列表、时间冲突提示、地图联动；不随意夸大数据准确度。
- 地图标签：缩小时合并，放大后按建筑与场地细分；选中状态高亮但不遮挡主要道路。
- 活动卡：时间和截止日期清晰，官方/非官方来源可辨，操作少而明确。
- 登录：简单、少字段，手机号 OTP；游客可轻松返回公共地图。

## 4. 桌面与手机布局

桌面：浮动左侧导航→中心大地图→右侧 Agent；地图拥有主要视觉比重。取消常驻顶层栏，品牌/校区整合在搜索浮层，账号/游客移至导航。右侧面板默认可收起，页面跳转保留会话。

手机：全屏地图、顶部搜索/分区切换、地图工具按钮、可拖动 AI 抽屉（收起/半屏/全屏）、底部五入口。浮层避开状态栏和底部安全区。

## 5. Apple 风格的边界

- 玻璃拟态只用于局部，不对整张地图全屏模糊。
- 动画以 150～250ms 短过渡为主；支持系统减少动态效果设置。
- 真实地理数据、道路标注和按钮可触达性高于动效美观。
- 必须保证文字对比度与触控命中面积；手机上不以 Hover 表示功能。
- 深色模式后期再做，不阻塞地图/Agent P0。

## 7. 设计到代码的验收方式

1. 建立 Tailwind 或 CSS tokens，所有组件共享色系与间距而不是局部硬编码。
2. 桌面 1440×900 与手机 390×844 作为常见视觉验证尺寸（还需更多设备宽度）。
3. UI 层鼠标/触摸滚动不干扰地图缩放；面板支持键盘关闭与焦点管理。
4. 文字、图标、选中与禁用状态均清晰；错误提示不靠单一颜色传达。
5. 对真实移动网络和低性能设备提供地图图层降级，保证导航/问答可用。
