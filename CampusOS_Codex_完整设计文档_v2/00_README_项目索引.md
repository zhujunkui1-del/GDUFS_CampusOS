## 1. 正确使用方式

1. 先完整阅读本文件和根目录 `AGENTS.md`，再读 `01_PRODUCT_SPEC.md`。
2. **不要立刻一口气实现所有模块。** 首先检查代码仓库、确认开发环境与授权；建立 `docs/PROGRESS.md`、`docs/DECISIONS.md`、`docs/BLOCKERS.md`。
3. 阅读本包中各模块文档，按 `09_DEVELOPMENT_PLAN.md` 的任务依赖，先打通真实、可测试的端到端链路。
4. **不允许用假地点、假路线、假活动、预设聊天答案或无效按钮冒充实际功能。** 可以使用隔离的测试夹具和单元测试模拟数据，生产应用不得混入。
5. 缺少学校开放接口、地图 POI、图片授权、API Key、短信资质等真实依赖时：记录阻塞、保留干净的适配器与可用功能；不要伪造“已绑定”“同步成功”。
6. 第三方网站获得的地图图片素材，在**项目负责人明确确认**且有使用许可前不得加入上线地图。用户提供的 2D 与鸟瞰图是已收悉的研究资料，**不等于其底图可直接重新分发**。
7. 网页与地图一律仅面向**广外大学城校区：教学区 + 生活区 + 南校人行隧道等连接道路**。知识库可收录与广外全校有关、适用范围正确的公告。

## 3. 关键决定（高于旧版项目草案）

以下是多轮讨论后的**更新决策**；若与旧版 `CampusOS_广外通_项目开发草案_Codex.md` 冲突，**以本包为准**：

- **有自有账号系统**：手机号验证码、账号找回、跨设备收藏/日程/会话；同时保留游客直接使用公共地图和校园问答。
- **学校统一身份**：优先研究一次获得学校正式授权后连接数智广外与教务服务。没有开放接口时不得模拟登录、索取教务密码/Cookie、伪装同步成功。
- **AI 架构**：方案 A，1 总控 Agent + 4 专业能力模块；16 项 Skill；结构化 Map Action 协议；RAG 与 GIS、活动库、个人库分离。
- **模型设置**（2026-10-12 新增）：个人中心内提供默认 DeepSeek/自定义 API 切换，不增加一级导航；游客可临时使用但不能保存配置/密钥，登录用户可保存多份加密配置并选择一份。完整约束以 `12_MODEL_API_SETTINGS.md` 为准；此规则取代原新增要求中“游客统一使用默认模型”。
- **RAG 内容发布**：方案 B，来源明确且校验通过的官方文章可自动索引；自动抽取的关键活动时间/地点未经核验不发布地图事件；群聊、小红书、第三方地图素材进入人工审核流程。
- **小红书**：尽可能利用合规可用的查询和用户提交链接，但不假设有全站搜索/批量读取 API；非官方信息只作为经验参考，始终保留原文跳转链接。
- **地图**：只绘制大学城；教学区、生活区、体育设施、宿舍逐栋标注、隧道连通导航必须完整；当前固定MapLibre/本地OSM，MapAdapter可替换，高德按需提供在线服务。默认2D，单按钮循环2D→2.5D→3D→2D；宿舍模板与批量性能门槛见 `docs/S1_BUILDING_MODEL_PLAN.md`。
- **前端**：仅做响应式 Web，不做独立 iOS/Android App；桌面左侧导航 + 中央地图 + 右侧可收起 Agent；手机全屏地图 + AI 底部抽屉。
- **视觉**：广外校园蓝白色，参考 Apple 的简洁和克制层次；视觉稿只是 UI 方向参考，不得当成真实广外 GIS 数据。
- **第九模块社交**：Campus Moments 属 P2。附近的人“查看附近用户”与“向别人显示我的位置”是不同开关，双默认关闭；只模糊展示位置且限时；动态绑定公共地点，不公开发帖精确轨迹。
