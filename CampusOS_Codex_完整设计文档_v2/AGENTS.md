# AGENTS.md｜广外通 CampusOS 长期开发规则

你是负责本项目的 Codex 工程代理。必须先阅读 `00_README_项目索引.md` 和相关模块文档，再修改代码。以下规则高于旧版项目草案；有冲突及时指出并以最新经负责人确认的决定为准。

1. 只构建广外**大学城校区**地图，**教学区 + 生活区 + 南校地下隧道与连接道路**都要覆盖；不开发白云山校区地图。
2. 主赛道生活服务，管理服务是办事指引；九模块中 **M09 校园空间社交为 P2**，不要挤占初赛核心工作。
3. **响应式 Web，不做原生 App**。桌面：左侧导航、地图主体、右侧全局 AI；手机：地图主体、底部 AI 抽屉。
4. 地图默认2D，单按钮循环2D→2.5D→3D→2D；地图地理准确、标注清楚与流畅优先于视觉特效，采用广外校园蓝白、Apple式简洁UI。南苑7栋已验收模型为宿舍模板；批量建模前按 `docs/S1_BUILDING_MODEL_PLAN.md` 的性能与资料门槛推进。
5. 不把生成视觉图、用户提供的地图图片或第三方网站地图当成可自由商用/再分发 GIS 数据；小红书等第三方地图**必须经负责人审核和许可核验**才能集成。
6. 高德/百度使用官方 SDK/合法 API，绝不未经许可抓取或重分发其瓦片、街景、POI 数据库、3D 模型。
7. 单总控 Agent + 四专业业务模块、16 项 Skill；Skill 要有真实接口、入参出参校验、权限、超时、错误码和自动化测试。
8. RAG 方案 B：校验通过的官方站点文章可自动索引；关键活动时间/地点未经核验不可自动标记地图；群聊、小红书和地图素材由人工审核。非官方消息只是参考且带原文链接。
9. 校园知识可覆盖广外全校，但**地图与线下路线只能定位大学城**；没有合法地理数据不猜测地点、宿舍编号、隧道入口或路线。
10. **有 CampusOS 自有账号系统 + 手机号找回 + 游客模式**。不使用旧版“不建账号”约束；游客可查地图、公共问答、活动与普通路线。
11. 数智广外/教务系统的绑定只能在**学校正式提供第三方授权**后实现，优先一次统一身份授权多个服务；不得代收学校密码、验证码或 Cookie，不得假装绑定成功。
12. Agent 可以读取已获授权的个人业务数据，但必须通过会话鉴权；高风险写入先用户确认；数据不能跨账号泄露。
13. 用户动态/“附近的人”P2：查看附近的人和公开自己位置双独立开关，默认关闭。位置模糊、短时、主动授权；社交内容不自动进入官方 RAG。
14. 公开的校园地点、官方政策、活动、路线时间必须可追溯、可验证；没有数据时显示真实空状态，不造假。
15. **简洁至上**：产品界面只保留名称、操作、必要业务信息和简短可行动的状态。不得添加小字解释段落、实现细节、来源审核说明或重复提示。来源、许可、核验与限制记录在工程文档；必要原文链接按需查看，版权署名保留。不可用功能使用准确的禁用状态，错误用正常字号的一句话和恢复操作表达。
16. 平台密钥与加密主密钥仅服务端 Secret 配置；用户自定义 Key 通过 HTTPS 交给服务端，登录用户持久密钥采用认证加密，游客仅当前页面内存临时使用。`.env.example` 可提交，真实凭据不得提交 Git；对上传文件、外部抓取、短信和用户输入设置权限/限流/审计。
17. 每个里程碑完成后运行 typecheck、lint、单元测试、关键 E2E 与生产构建；把结果写 `docs/PROGRESS.md`。
18. 需要收费、影响隐私、引入第三方未经批准地图素材、扩展校区、替换关键架构或访问学校系统时，先暂停相关步骤并请求负责人批准；对其余不依赖部分继续开发。
19. 优先 P0：真实地图→地点路线→Agent Skill→RAG 溯源→可公开使用网站；P1：多站、课表、个人化、视觉完善；P2：学校授权接口与校园社交。
20. 在 `docs/DATA_SOURCES.md` 记录每个地点/道路/图片/知识源的 URL、许可状态、核验时间、负责人决策；不因比赛非商业属性默认豁免第三方平台条款。
21. 修改模型设置、供应商适配、连接测试、凭据处理或 Agent 模型选择前，完整阅读 `12_MODEL_API_SETTINGS.md`。默认模型为 DeepSeek；游客可临时使用自定义 API，只有登录用户可持久保存。模型调用仅在服务端，端点按审核白名单约束，自定义失败后须由用户明确选择才能切换至平台模型；不能自动消耗平台额度。

首次执行先检查现有仓库，若旧文件仍含“不自建账号”“仅教学区”等过时指令，应给出修订清单，不能无声沿用。
